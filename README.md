# 开拍 RALLY

A free, open-source 3D badminton game for mobile and desktop browsers.

正式版定位为**人机练习＋局域网好友实时 1V1**，支持浮动摇杆、可调视角与本服务器排行榜。使用 Three.js 和 Node.js，可自行运行和修改，采用 [MIT 许可证](LICENSE)。不需要第三方 API Key，也不需要购买公网服务器。

**[打开网页版 →](https://zcinta0514.github.io/rally-badminton/)** · 手机建议横屏。在线入口可直接练习人机；点击「好友对打」，粘贴主机电脑提供的局域网地址或邀请链接，即可切换到创建、加入房间的完整游戏页面。

![1.1 手机横屏比赛画面](docs/images/gameplay.png)

## 快速运行

安装 **Node.js 22 或更新版本**，然后执行：

```sh
git clone https://github.com/zcinta0514/rally-badminton.git
cd rally-badminton
npm ci
npm start
```

电脑打开 **http://localhost:3000/**。手机与电脑连接同一 Wi-Fi，或连接支持设备互访的同一热点，使用启动终端显示的局域网地址打开；手机上的 `localhost` 指向手机自身。主机电脑和 `npm start` 服务需在游玩期间持续运行。

## 怎么和朋友联机

1. 一台主机电脑运行 `npm start`。两位玩家与主机连接同一 Wi-Fi，或支持设备互访的同一热点。
2. 两个人都打开主机启动终端显示的**同一个局域网网址**。也可在网页版的「好友对打」中粘贴该地址后进入。
3. 房主选择角色、分制，填写昵称并创建房间，分享邀请链接或 **5 位房间码**。
4. 对方在同一局域网网址填写昵称和房间码后加入，双方自动进入 1V1；结束后双方同意可再来一局。

**房间码必须在创建该房间的同一服务器网址使用。** 从在线人机入口进入好友说明后，需要切换到这个局域网网址；房间码本身不是服务器地址。主机停止或重启后，原房间失效。

本版提供局域网邀请对打，没有随机匹配；公网联机不属于本版交付范围。完整步骤和可选 HTTPS 离线主屏幕配置见 [运行指南](docs/DEPLOYMENT.md)。

## 操作

| 操作 | 手机横屏 | 电脑 |
| --- | --- | --- |
| 移动 | 左半屏空白处按下出现摇杆，拖动移动，松手收起 | WASD / 方向键 |
| 高远 / 吊球 / 杀球 | 右侧三个击球按钮 | J / K / L |
| 力量与落点 | 按住击球键蓄力，同时拖动选落点，松手击球 | 鼠标拖动按钮；Z / X / C 预选线路 |
| 暂停 | 右上暂停按钮 | Esc |

先跑到来球附近再击球。青色圈提示来球落点，琥珀色弧提示接球位置，按住击球时的粉色圈表示意图落点。实际球路受站位、触球高度、移动、体力和蓄力影响。

## 已有功能

- 三种角色打法、三档人机；5 / 11 / 21 分快赛与简化标准三局赛。
- 服务端计算真人比赛的移动、触球和得分；同步暂停、重连和再战。
- 左上窄比分栏、浮动摇杆、多指击球、居中镜头与视角设置。
- 排行榜按胜场、胜率、累计得分排序，仅统计该服务器已结束的真人 1V1；人机练习不计入。
- 原创连续蒙皮人物、关节与急停动作，16 羽片球体、触网摆动、冷暖场馆灯光和浏览器合成音效。
- 可选可信 HTTPS 主屏幕版，完整缓存就绪后支持离线人机；普通局域网 HTTP 即可好友对打。

昵称不是注册账号。战绩绑定浏览器保存的匿名凭据，改名保留战绩，换设备或清除网站数据会成为新身份。同名不会恢复旧战绩。各服务器之间不共享排行榜。

## 开发

```sh
npm test
npm run build
```

构建导出自带 Three.js 的 `dist/` 静态包。普通入口是 `/`，人物预览是 `/?preview=athlete`。服务启动时固定客户端资源，修改源码后需重启服务。

| 目录 | 作用 |
| --- | --- |
| `src/` | 输入、界面、渲染、人物与声音 |
| `shared/` | 客户端与服务端共享的规则和球路计算 |
| `server/` | 房间、WebSocket 同步与排行榜 |
| `scripts/` | 静态构建、离线缓存与图标生成 |
| `tests/` | 规则、输入、联机、持久化与渲染状态测试 |
| `deploy/` | 不含凭据的环境变量与 Nginx 示例 |

参与开发见 [贡献指南](CONTRIBUTING.md)，版本变化见 [CHANGELOG](CHANGELOG.md)，安全报告见 [SECURITY](SECURITY.md)。

## 当前边界

人物使用程序化动画，球路采用简化抛体模型，尚无完整空气阻力、专业动捕、随机匹配或跨设备账号。画面与延迟需要在目标手机上验证，桌面测试不代表 iPhone 帧率。
