2. 在「配置 → 事件管理 → 代码埋点事件 → 创建代码事件」建下面八项，生效范围选全部页面。中文填「事件名称」，英文填「事件标识」。

| 事件名称 | 事件标识 |
| --- | --- |
| 人机开局 | `ai_start` |
| 好友开局 | `friend_start` |

| 好友完赛 | `friend_finish` |

3. 把应用的**统计代码**复制给 Codex。这是公开嵌入代码，包含 `id`、`ck`；不要发送密码、验证码或登录令牌。后续配置代码、发布和验证由 Codex 处理。

仅配置公开编号不会自动建立后台事件；上述八项也需要完成，才能查看游戏次数和降级情况。

## 每个数字是什么意思

| 数字／事件名 | 含义 |
| --- | --- |
| 浏览量 PV | 打开、重新打开或刷新游戏页面的次数；一个人可以贡献多次。 |
| 访客数 UV | 51LA 通过浏览器标识等信息估算的访客规模。换浏览器、换设备、清理存储或更换网站入口可能再次计入；不是实名人数。不要把每日 UV 简单相加称为累计独立人数。 |
| `ai_start`：人机开局 | 玩家进入人机比赛一次；再来一局会增加。首页自动演示不计入。 |
| `friend_start`：好友开局 | 进入好友比赛的参与次数；两台手机通常合计两次。只建房未进入比赛不计入。 |
| `ai_finish`：人机完赛 | 人机比赛按分数正常结束的参与次数。中途退出和暂停超时不计入。 |
| `friend_finish`：好友完赛 | 好友比赛按分数正常结束的参与次数；双方通常各记一次。 |
| `ai_interrupt`：人机中断 | 人机比赛在正常完赛前退出、断开或被中止的次数。 |
| `friend_interrupt`：好友中断 | 好友比赛在正常完赛前退出、断开或被中止的次数。 |
| `network_degraded`：网络降级 | 一局好友对打中出现明显快照抖动、播放欠载或快照过期；每局最多一次。 |
| `performance_degraded`：性能降级 | 一局比赛中自适应画质降低；每局最多一次。 |

两个 start 相加，得到**累计开局参与次数**；两个 finish 相加，得到**累计完赛参与次数**。中断与降级事件用于定位体验问题，不与完赛次数相加。事件报表看「触发次数」，不把所有事件、点击或滚动的数量当成游戏次数。

作品／项目申请可以写：“截至 YYYY-MM-DD，网站累计浏览 X 次，统计期内估算访客 Y，累计开局参与 Z 次。”附上相同日期范围的后台截图。统计从正式接入开始，不能补出此前的历史使用量。

## 玩家隐私和关闭方式

游戏「操作说明 → 基础使用统计与隐私」提供说明和开关。关闭后移除统计页、停止继续发送并清理本机待传队列；尊重浏览器 Do Not Track。关闭不影响玩法。

51LA 会处理 IP、浏览器、设备等访问信息，使用浏览器存储识别访客。游戏只向独立的统计页传入公开应用编号和八种固定事件名，不传昵称、玩家密钥、房间码、对手信息、原始输入轨迹或邀请链接。来源只保留站点 origin。未开启屏幕录制。作者后台需要账号登录；不要将后台共享链接公开。

## 技术维护

- 账号初始化：添加一个应用，域名填 `zcinta0514.github.io` 与 `kaipai-rally.vercel.app`（分行）。在[配置 → 事件管理](https://v6.51.la/report/setup/data_manage)选择「代码埋点事件 → 创建代码事件」，按上表建立八项：中文名称用于显示，英文事件标识必须与代码一致；生效范围为全部页面。公开 id/ck 只能配置采集目标，**不会自动在后台建立事件定义**。需要登录账号完成这一步后验证报表。
- 根目录 `analytics.config.json` 只放官方统计代码中的公开 `id`、`ck`，大小写保持原样。它们是公开采集标识，不是密码；不得填 API key、登录令牌或账号密码。两项都为空表示关闭。
- 构建生成的 `runtime-config.js` 包含公开编号。GitHub Pages、Vercel 和 Node 服务使用同一配置构建；配置变更后重新构建／重启。旧 PWA 标签页需关闭后重开并核对实际资源版本。
- `src/analytics.js` 管理开关、生产域名范围、游戏事件和有限重试；`src/analytics-frame.html` / `.js` 在空白同源 iframe 内加载官方 `https://sdk.51.la/js-sdk-pro.min.js`。
- SDK 的自动点击监听只初始化在没有游戏界面内容的统计页内，`autoTrack: true` 用于加载事件 SDK；`screenRecord: false`、`hashMode: false`。不通过反复初始化补造历史 PV。基础 PV 初始化已开始而事件扩展失败时，本页停止自动重建，事件留待下次真实打开补传；基础脚本尚未加载则可以联网重试。玩家主动关闭再开启统计会建立新的统计会话。报表路径将显示固定的 `src/analytics-frame.html`，它代表主游戏的一次页面打开。
- 创建统计页前把主文档 referrer 缩减为 origin，因为 SDK 会读取顶层 referrer；无法安全缩减时不加载采集。游戏自身的邀请地址不变。iframe 不是针对恶意第三方脚本的安全隔离，仍需信任官方 SDK。
- 页面间消息校验同源和发送窗口，事件只有固定枚举、请求编号；不接收任意名称或属性。SDK 加载失败不会阻止游戏。
- 统计页的本地 HTML／JS 纳入离线资源快照；外部 SDK 不属于游戏离线必需资源。
