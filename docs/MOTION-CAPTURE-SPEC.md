# P0-4／P1-3 羽毛球专项动作采集规格

规格版本 rally-capture/2.0，2026-10-03。用户已同意按运动人物与动作约束重建方向开工，优先细化最高质量采集。不以成本、时间、算力筛选方案，面部次要。当前实际进度以 [PROJECT-STATUS.md](PROJECT-STATUS.md) 为准。

本规格选择**专业球员完整回合、全场光学身体采集与局部高速触球观测同步**的主路线。设备、人员和场地尚未落实；下列配置是试采候选，不是已实现性能或国际认证等级。严格指标的唯一数值依据是 [测量与质量门槛](CAPTURE-QUALITY-GATES.md)。本版取代旧版 120 Hz／240 FPS、5 ms 同步、10 ms 事件误差等首轮要求；旧资料仍可作有来源标签的参考，不追认其通过新规格。

配套：[现场拍摄清单](CAPTURE-SHOOT-PLAN.md)、[供应方技术简报](CAPTURE-SUPPLIER-BRIEF.md)、[机器可读计划与模板](../assets/motion/capture/README.md)、[重建路线](RIG-MOTION-REBUILD-RECOMMENDATION.md)。

## 1. 路线选择与试采要回答的问题

| 路线 | 本项目用途 | 需要解决的质量边界 |
| --- | --- | --- |
| 全场光学＋局部高速多视角＋专项手部／接地测量 | 主路线；先验证最难小样再扩采 | 高速遮挡、设备改变技术、软组织误差、球拍非刚性、跨系统同步均需独立证明 |
| 惯性身体／手套＋参考视频 | 经标定的补充通道；同一试采证明质量提升后使用 | 漂移、磁干扰、前臂轴向、手套滑移不能靠光滑输出掩盖 |
| 无标记多视角／Pose2Sim | 无穿戴基准、交叉检查、部分身体观察 | 不能将估计的手指、球头、局部弦面和肩胛运动当原始真值 |
| 单目生成／通用动作库 | 技术分析、既有原型 | 无法补回从未观测的真实接触与高速旋转，不作为最终来源主线 |

架构选择不等于厂商选择。用同样的真实球员、球场、球拍、留出动作和判据比较候选供应方；严格项逐项通过后，再比较正常速度技术表现、尾部误差、缺失和修补负担，不用总分抵消某个失败项。达不到要求时改机位、照明、量具、标记或方法并重采，不降低门槛换通过。

## 2. 双尺度观测系统

### 全场身体与完整步法

- 覆盖实际双打场地大小的完整可用空间、边线外制动区和跳起后的最高拍头，记录测量体积边界。以场地测量和专业球员实际可用范围定机位，不把镜头数量当覆盖证明。
- 初始设计约 24–40 台高端光学机位、上下两层并补角落／网边遮挡；按现场可观测性增配。身体原始频率候选 500–1000 Hz，实际以所选模式下的小标记动态可辨性、独立误差、曝光与同步表现确定。
- 两名球员同时记录，标记身份不得在交叉遮挡时互换。包括躯干、肩带、上臂与前臂轴向、骨盆、膝踝、后跟／前掌／足趾；另交静态与功能性标定。皮肤标记精度不等于真实骨轴或关节中心精度。
- 至少正面、侧面和斜后方全身参考视频，脚底、球拍、对手和来球不断出画。原生 240–500 FPS 可作为全身慢放候选，另交正常速度参考；不能替代局部高速触球证据。

### 局部球拍、球头与握拍

- 每个关键触球区至少两台可用的校准高速机位形成三维观测，设计第三视角处理遮挡。独立精度验证另需未参与当前解算／标定拟合的参考链；第三台相机本身不等于独立参考。
- 原生 10,000–20,000 FPS、全局快门是高速触球初始候选。由实际相对速度、视野像素尺度、曝光拖影、信噪比及总误差预算决定最终配置；杀球更快或局部难辨时继续提高观测能力。不能只裁到极小 ROI 后要求球员扭曲动作迁就取景。
- 分别观察拍柄、拍杆、拍框及接触处弦面。柄的 6DoF 用于握拍和一般动作，触球处使用实际局部表面；测杆弯曲／扭转和弦床形变残差。球头中心、外轮廓与接触点分别定义，不能用羽裙质心代替球头。
- 优先无标记高速追踪羽毛球；器材贴点／加传感器必须测安装前后质量、重心、可测惯量，并做不带设备的动作 A/B。附加质量、贴点位置、胶带和握柄变化随交付记录。
- 手部用局部多视角观察腕、拇指、食指、握柄切换和余指握持；经验证的手套只作补充。被握柄完全遮挡的手指可估计并精修，但逐段标 estimated／authored，不能声称已测到指骨、握力或拇指发力。脸部只保留头部朝向与必要参考，不单开面部捕捉主线。

### 支撑、落地与发力

- 场地齐平、与运动地板刚度及摩擦条件一致的多块六分量力台，原生 2000 Hz 或以上作为候选；另核验机械带宽、量程、峰值饱和、零点与系统延迟。不得暴露台边或迫使球员瞄准台面落脚。
- 全回合以自然步法为先。力台外标 not_measured，踩边／无法分离双脚标 partial／unseparable。专项力学小样可单列，不能说所有完整回合都有全程实测地面反力。
- 200–500 Hz 鞋内压力是接触阶段的辅助候选，检查是否改变鞋内贴合；压力不等于六分量地面反力。共享接口中的 loadFraction／balance 是控制估计，不映射为实测力或人体平衡真值。

## 3. 时钟、标定与独立证据

1. 选主硬件时基；逐台记录触发、真实曝光起止／中心、设备时间戳到主时钟的映射。优先共享时钟和曝光同步，不能用软件同时启动或视频时间码代替。连续脉冲／共同可观测事件覆盖每条 take 内部及首尾；检查时钟重启、温漂、漏帧和重复帧。
2. 关键触球链执行质量门槛的严格同步与事件预算。其他通道也必须量测偏移与漂移；未达到严格链要求的辅助手套、鞋垫或音频只能按实际不确定度用于相应分析，不能进入严格触球时间依据。身体离散采样的插值误差另计，不能继承局部高速链的精度。
3. 独立量具、动态参考轨迹、标定保留样本覆盖场地中心、边角、地面、头顶、真实速度与遮挡。重新摆机、焦距／对焦、ROI、帧率、地面、网柱、贴点或器材变更后，做影响分析并重新标定相关链。
4. 保存相机内外参、畸变、镜头设置、标定残差、独立参考不确定度、测量体积与失效区域。同步、空间、事件判读、形变、软组织误差分别报告。
5. 保留设备原坐标与单位；交到 RALLY 的 4×4 变换、矩阵行列约定和验证点。目标为右手系、米、秒、弧度、+Y 向上，场地中心地面为原点，side 0 位于 +Z。球员换端不镜像坐标系；四元数 xyzw、法向正反面和角度展开明确。
6. 事件标注为首次物理接触 contact_start 与分离 contact_end 的区间和证据，不能仅给最近距离那一帧。估计重心、局部接触点与甜区几何分开。标注分歧保留双人原判和复核理由；按保守相对速度传播总不确定度。

全部 p95／max／U95 及统计口径执行 [CAPTURE-QUALITY-GATES.md](CAPTURE-QUALITY-GATES.md)，不另设放宽版。严格同步表适用于进入严格触球观测链的通道；其他辅助手段也必须报告实测同步，不能冒称达到同等精度。

## 4. 人员、场地与试采顺序

配置主专业球员（首轮右手）、同水平陪练、专业教练、光学采集负责人、测量／生物力学工程师、手部与球拍观测负责人、Blender 动画／绑定负责人、数据 QA。角色可由有相应能力者兼任，但关键结论应由未负责该段清理的人复查；尚未安排具体人员，不虚构签署意见。

真实球鞋、球拍、羽毛球、网和运动地面，记录器材规格、穿线、温湿度、照明与气流。先热身和无设备自然动作，安装后对照；出现持拍／落地改变则调整方案。球员与教练决定可执行强度和休息，记录疲劳、技术变形与失误，不为凑数量连续做极限跳杀。

执行次序：场地／时钟验收 → 身体与器材标定 → 无设备 A/B → 六类技术的两端小样 → 三类连续回合 → 当场复核与补采 → 留出数据锁定 → L0／L1 复现 → Blender 小样 → 真实运行验收 → 扩采五组。详细 IDs、数量与留出规则见拍摄清单。失败尝试也保留，采够条数不表示质量通过。

## 5. 数据交付与事件语义

交付保留四层：L0 原始观测、L1 清理与运动解算、L2 Blender 重定向母版、L3 最终实时结果。各层有独立版本、输入 SHA256、处理工具／配置与 QA；不得用 L2 美化后的轨迹覆盖 L0。

- 原始厂商文件、未滤波标记／模拟通道，以及无损或原始质量同步视频；C3D／TRC 等开放导出与原始文件共同保留。真正没有观测的数据留缺失。
- 相机、人体功能性标定、球拍／羽毛球尺寸、地面／力台、全时段同步表、原始时间戳及丢帧清单；逐通道记录采样率、曝光、单位、精度与适用时间段。
- 身体骨架 FBX／BVH 和关节定义；独立球拍、球头与手部时间序列；有明确时间戳的 CSV／JSON 或等价开放数据，记录速度计算和滤波方法。
- 触球起止、脚部承重／推蹬／腾空／着地窗口、握拍切换、随挥结束、制动、恢复平衡与下一次启动。战术回位到达另标，连续平抽不强制回中心。每项含 observed／estimated／interpolated／authored 等来源及缺失区间。
- 技术、主动／被动、入球方向与可观测速度、触点高度、身体姿态、握拍、失误原因。无法量测的速度留 null 并说明，不得由技术名称编造。
- 可编辑 .blend 母版（制作控制器／变形骨架分离、修形可追溯），以及导出 FBX／GLB。Blender 约束、驱动器和 B-Bones 不作为 GLB 自动支持的能力；具体烘焙、辅助骨、顶点影响及运行修形由独立导出实验验证。
- [MotionClipMetadata](../shared/play-contract.d.ts) 是游戏动作索引目标，不能容纳全部科学原始数据。采集事件与误差预算存独立 sidecar；导入时建立 clipId ↔ takeId ↔ 事件 ID ↔ 来源文件／时间段映射。60 Hz tick／subTick 是派生表示，不能覆盖原始秒级时间戳。

交付目录：raw/<takeId>/、calibration/、sync/、annotations/、processed/<revision>/、blender/、exports/、qa/、rights/、manifest.json。模板和填报说明在 [assets/motion/capture](../assets/motion/capture/README.md)；null 与空列表表示未交付，不表示零误差或通过。摄制原件存受控资产库，不进入客户端静态资源或公开 Git。

## 6. 到 Blender 和最终运动人物的实施路径

短发球检验手、放球与低位接触；被动防守检验前臂轴向、深屈肘和收拍避身；后场高远／跳杀检验肩胛—肩—肘—腕顺序、拍杆形变、剪刀步和落地。连续回合检验技术切换与恢复，不能由单次精修结果推断。

身体比例／关节轴标定后，建立解剖约束明确的制作控制骨架，再定义独立变形与运行骨架。允许新底模或重拓扑；先检查肩、肘、前臂、髋、踝及足趾运动，不把旧 71 骨或四权重当母版限制。重定向同时维护持拍、足地、球路及身体可达性；只平移手腕去追触点不通过。

Blender 保留原始运动、清理版、重定向版和精修版对照；球拍／球头为独立对象，足部后跟／前掌／脚趾分别验证。动画师可以修复表现，但人工补出的片段保留标签。手指遮挡、真实骨轴缺失不能由“算力不限”变成实测。

L2 完整小样通过后，以同样时间轴导出游戏候选，在混合、接地、全身约束、辅助骨和修形之后检查真实表面。对齐 P0 五组回放并加入留出速度／触点；正常速度专业复核、用户视觉验收与真实手机表现都是必要项。采集完成不自动勾选 P1-1／P1-5／P3。

## 7. 权利、候选设备资料与放行

供应方需明确原始数据永久保存与再处理、动作清理／重定向／衍生、游戏内分发、商业用途和跨平台范围；分别覆盖球员表演／肖像、场地拍摄、第三方素材、供应方输出及工具／模型／数据许可。联系方式和合同原件放受控目录，项目只记录证据 ID、范围与状态。未核实的材料不能写已授权。现有 MultiSense 沿用已有来源记录，本规格不扩展其权利或技术覆盖。

- [Qualisys Arqus 官方模式表](https://docs.qualisys.com/qtm/content/techref/arqus_model_specs.htm)已读到 A12 常规 12 MP／300 Hz、高速 3 MP／1040 Hz；A5 常规 5 MP／700 Hz、高速 1 MP／1400 Hz。只证明候选模式存在，不证明全场小标记、人体骨角或整链达到本项目精度。来源副本在 artifacts/capture-prep/20261002/sources/qualisys-partial.html（保留下载过程命名）。
- 2026-10-03 后续已取得 Vicon Valkyrie 与 Phantom TMX 官方 PDF；具体模式、曝光、内存与证据边界见 [供应方预审](CAPTURE-SUPPLIER-PREVIEW.md)。Lock PDF 已下载但正文未完成解析；Photron 仍待资料。官方模式不证明本场地精度，供应方仍须交原始小样。局部高速可增加 50k／76k fps 对照，需证明照明、分段触发、再武装与连续回合事件覆盖，不能假设整场连续写盘。
- 不指定单一品牌“最优”。当前选择的是组合观测架构；最终设备组合由同条件试采、独立证据和呈现质量决定。

供应方技术回复与试采质量、权利范围、完整报价形成可审查材料后再推进实际外部安排。当前完成采集准备规格，不代表已采购、联系、拍摄、重建模型或通过运动验收。
