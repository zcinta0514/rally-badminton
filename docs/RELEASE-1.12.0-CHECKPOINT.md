2026-10-31。用户要求合并本轮 UI-2 改动，并明确合入前核对品牌标志与线上一致、不得改动标志。线上最新发布为 1.11.0（7164832c）；本轮整理为主线之后的界面与触感更新，按次版本 1.12.0 准备。

## 范围

- 球场白主题覆盖首页、开局、好友房间、暂停、结算、排行榜、操作说明、意见反馈、设置、教学和安装/更新公告。

- 竖屏安装版按系统安全区排版，状态栏、底部 Home 条和横向锁定一起处理。

- `icons/rally.svg`、`icons/rally-192.png`、`icons/rally-512.png`、`icons/apple-touch-icon.png` 与 `origin/main` 逐字节一致。
- brand 链接、标志 SVG 路径与 `origin/main` 文本一致；计算样式核对：底色 `rgb(0,134,80)`、下边线 `5px solid rgb(7,86,176)`、图形白色、矩形 `[32, 8.5, 42, 42]`。
- 字标“开拍 RALLY”的字号、字重、字距、间距、深色 `rgb(18,43,37)` 与矩形 `[32, 8.5, 102, 42]` 与主线一致；主题层显式固定字标颜色，避免跟随新主题色偏移。
- 结论：标志未改。
