## 实现与取舍

- 新增共享解析水平二次阻力：dv/dt=-.2|v水平|v水平，竖直保留重力9.81。出球、过网、落点、AI拦截、辅助提示和联机插值共用同一运动解。系数.2是校准初值，不声称从单机位录像精确拟合；这仍是节奏近似，缺少完整三维空气阻力和羽毛球姿态。
- 高发球与头顶高远分别设定飞行时间，保留深度和高度。真实录像支持适当的高弧线准备时间，因此相较此前只追求提速的候选有所回调。均衡固定场景：高发球落地1.8019s、顶点4.5398m、下降至3.05m时1.3910s；后场高远落地1.5861s、顶点4.5218m、下降至3.05m时1.1737s。它们是代表性游戏夹具，不是录像逐球三维重建。
- 均衡起步.4s位移1.5062→1.2712m，基础加速度30→18、制动38→26，99%全速.1583→.2583s，反向全速.2750→.4333s。最高跑速仍均衡4.6、灵巧5.35、力量4.05m/s；这些是保留的玩法差异，不能称为录像测得的三种人类速度。
- 固定吊球落地.9825s，杀球落地.5865s；杀球水平初速约52m/s并持续衰减。不能把它与录像.60s触球间隔直接等同。
- 修正高速球揭示的触球计时：物理切片精确切到contactAt，触球瞬间不再额外推进出球。网络回放同步解析减速，并对包端点微小误差作连续校正。协议8→9阻止混用旧规则。
- 保留有限.54s输入缓存、最低.22m触点与1.45m基础范围。及时上网在.8633s接到吊球，质量.5442；迟.55/.66s启动均没赶到。较弱救球在.2559m触球、质量.1825并下网。合理站位接杀成功，明显失位仍丢分。
- 浏览器验证发现匿名pointer事件与键盘击球的pointerId均为undefined时会错误认领，并可能空引用。现要求明确的触点所有者；新增回归覆盖空闲与键盘蓄力时的匿名移动、释放和取消。

修改范围复核：共享球物理必须同时接入联机回放，否则服务与画面球路不同；人物测试只改精确触球采样与真正快速下落夹具，未改人物实现或资产。触控修复是实测发现的三行输入归属修正。以上同属可独立试玩的PACE-1候选。
