# AI-1 高远球／吊球后的调整恢复

2026-10-05，继承本地候选 74f6862 与已联网核验的 main db8d453。用户选择“击球后休整加成”，在同一未发布候选分支继续实现；原根目录 P1 未修改，正式线上未更新，游戏版本号未递增。

## 机制

- 高远球实际触球后，在 2.2 秒窗口内满足既有调整恢复条件时，基础恢复速率加快 40%，每球额外最多 1.2 点。
- 吊球对应 1.2 秒窗口、加快 20%、额外最多 0.5 点。
- 击球成本先正常扣除，没有即时返还。两侧使用同一规则，三打法仍以各自恢复速率、挥拍冷却和消耗决定净收益。
- 加成须通过原有低强度阈值及连续 .35 秒等待；跑动／准备／挥拍／冷却仍阻断恢复。杀球、发球和未触球不产生加成。
- 对方触球、窗口到期、得分、暂停和比赛结束关闭加成；下一次触球替换预算，不能叠加。恢复不能超过角色上限。
- 上一轮每分定量恢复、低体力机会杀球与全部速度／加速／控制疲劳惩罚保留。没有引入 AI 专属补体力或新增预测误差。
- 规则摘要同步说明加成。序列化的 shotRecovery 含 type/expiresAt/remaining，直连快照校验其类型和预算。运行兼容协议改为5，防止旧候选规则混用；游戏发布号仍1.8.0。
