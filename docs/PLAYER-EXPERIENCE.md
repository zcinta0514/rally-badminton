本批包含新手入门、操作文字提示开关与自动更新。用户于 2026-09-12 明确授权开发。开发分支为 `codex/player-experience`，基于本地已提交主体升级 `6f671d2`，保留现有统计、手机直连、普通/父子局及本机战绩。

原目录的路线图和人物工作树的未提交动画/模型未由本任务修改。GitHub 远端连接失败，实施依据为已核对的本地提交及工作树；整合发布前必须再次核对远端与人物任务的最新功能。本文件不代表线上发布。

## 页面使用

首次加载完成后展示三步可跳过的玩法与操作教学。首页“新手入门”、操作说明内“再看三步教学”可重看。邀请链接优先展示加入流程并保留房间参数，教学延后。已完成或跳过的教学不会在每次打开时重复。

“操作说明”内可关闭“显示操作文字提示”，收起静态说明、键位和图例；按钮名称、体力、球场实时落点和风险继续显示。该选择保存在当前浏览器。

## 自动更新的实际边界

- 首开、回前台、恢复联网和已加载大厅中节流检查；应用主动检查至少间隔 60 秒，等待中的协调重试至少间隔 15 秒。比赛中延后应用主动检查和下载，回到空闲大厅再继续。关闭的网页不承诺在系统后台持续下载。
- 资源完整下载并校验后才进入可更新状态。发起自动更新的窗口须在前台且大厅空闲；其他能响应的后台大厅窗口可以共同切换。
- 未加载完成、比赛/暂停/局间、等待好友、重连、赛后动画或结算、打开弹层或编辑内容时均延后。短暂交互结束后留出空闲时间再协调。
- 只协调游戏入口的顶层/独立窗口。统计 iframe 和其他无游戏版本标记的页面不阻塞游戏切换；iframe 文档及其后续资源也按版本读取。
- 先进行不锁界面的安全探测，所有窗口响应后才短暂锁定开局/输入并复核。窗口集合改变、旧客户端无协议、窗口无响应或存储不可用时取消，继续现有游戏。
- 控制器版本与目标匹配后，每个来源/目标版本组合在同一页面会话中最多自动刷新一次；以页面内的真实 `RALLY_CONFIG.buildId` 确认更新。首次安装不会无条件刷新。
- 保留昵称与战绩；角色、难度、分制、规则和静音通过一次性会话快照恢复，保存失败则拒绝自动切换。普通启动的默认行为保持不变。
- 浏览器返回到缓存页面后恢复检查；如其他窗口已激活新版，等此页面空闲后再切换。激活或版本回复迟到、超过输入锁期限时也会在安全条件下重新核验。根目录及子路径下的 `index.html` 书签入口均绑定正确版本。
- 缓存维护有 7 天宽限，保留当前、最近上一完整版本、活跃及近期引用版本；不清理其他网站缓存，存储维护失败不阻止游玩。
- 连续频繁更新仍需要额外缓存空间；下载/校验失败时保留旧版，不将半个新版标成可用。

旧版第一次迁移没有新协调逻辑：联网在原主屏幕说明中检查更新，资源就绪后关闭所有旧游戏窗口，稍等片刻再打开，让浏览器完成首次接替。无需删除主屏幕图标或清除网站数据。完成这一次迁移后，后续新版可使用自动流程。

## 模块位置

- `src/onboarding.js` / `.css`：新手引导和提示偏好。
- `src/update-client.js`：安全状态、更新协调、交互锁和刷新保护。
- `src/update-preferences.js`：自动更新时的一次性设置恢复。
- `src/pwa.js`：现有安装入口与更新状态展示。
- `scripts/service-worker.js`：完整下载、窗口协调、页面版本绑定和缓存维护。
- `scripts/build-pwa.js`：真实页面构建 ID 和最终资源完整性哈希。

## 可重复验证

```powershell
node --test tests/*.test.js
npm run build
```

真实浏览器验收脚本为 `scripts/verify-player-experience.mjs`，需要独立可用的 Playwright 与 Chromium/Edge。设置 `RALLY_PLAYWRIGHT_MODULE` 为 Playwright 模块位置，`RALLY_BROWSER_PATH` 为浏览器程序位置后运行脚本。可选 `RALLY_LEGACY_ROOT` 指向只读旧版源码以验证首次迁移。测试只启动自己的临时服务，不向线上发送数据。

结果和截图写入忽略目录 `artifacts/player-experience/`。脚本检验新手完整流程、提示范围、设置保留、连续三个构建的多窗口自动更新及子路径离线入口。桌面浏览器模拟移动视口不等于真实 iPhone/安卓机验证。

2026-09-13 开发验收覆盖全量自动测试、根路径及 `/rally-badminton/` 构建。Edge 实际浏览器流程包含新手教学、操作提示、多窗口比赛延后、自动切换保留设置、子路径 `index.html` 离线模块及旧版关闭全部窗口后的迁移。测试宿主的 SwiftShader 曾出现长时间渲染任务，因此浏览器验收允许最多 120 秒加载；产品的安全探测、准备与输入锁时限没有放宽。真实手机性能仍需在目标设备验证。

本地 Node 服务在启动时构建资源快照。源码变更后重启，再核对浏览器的 `RALLY_CONFIG.buildId` 与实际功能。正式发布需分别验证 GitHub Pages 子路径和 Vercel 根路径，不能将源码提交视为部署成功。
