# P1-3B 进度、效果与路线评估

2026-10-04。依据实际候选、脚本与 artifacts/skin-repair/20261004/checkpoint.json；不是新动作或人物验收。

## 判断

保留“Blender 制作、参考动作与许可适用动捕结合、Three.js 实际比赛验收”的总体路线。停止把“旧表面/旧权重迁移到新 Rigify，再用局部平滑修补”作为生产主线。当前证据不足以认定 Blender 或 Rigify 不适用，但足以否决本项目这组迁移绑定候选。

用户目标是自然、真实的身体运动、受力与衔接；面相细节优先级低。降低面部细节不能解决肩腋、手腕和衣物的绑定缺陷。后续不以增加骨数、片段数、测试数代替可见效果。

## 之前执行上的错误

- 没有先证明新绑定的动态表面完整性，就开始编排三个动作并发出视频。
- 用手工设定的轨迹代替充分的参考分析；教学原理、原创编排与实测时序没有转化成足够自然的动作。
- 验证重心偏向导出/标记一致性，人体表面与正常速度观感落后；多个失败候选被误当作可交付进度。
- 多次局部修补没有整体通过，却没有及时淘汰这条具体实现。

## 调整后的实施方法

1. **先选一体化的人物运动底座。** 在同一来源、同一休止姿态下取得或建立身体拓扑、骨架和蒙皮，避免再次把几套不匹配的绑定直接拼起来。新资产与原P1作同条件对照；外部资产只有来源、许可与实际变形检查通过后才采用，不凭宣传页推荐。允许简洁面部和基础运动服，不降低身体/手/足要求。
2. **先过人体变形关。** 抬臂、深屈肘、前臂旋转、深蹲、弓步和转体；同时检查裸身体诊断层与正常着装层。身体、衣物、握拍分别检查，Blender 与实际导出都要通过。基础动作本身即失败的资产直接淘汰，不先扩展动作。
3. **再制作一个完整后场击球样段。** 用已有 Expert 身体数据与对应视频核查节奏，按角色比例重定向；不足部分明确人工制作。真实感重点是蹬地、髋肩顺序、挥拍加速、随挥、落地与恢复。先通过这一段，再扩展发球与弓步，避免三段同时扩散问题。
4. **同一比赛场景正常速度评审。** 人物、球拍、羽毛球及脚步时间一致，显示完整身体和完整恢复过程。只要仍有明显裂开、滑步、关节翻转或不自然停顿，就不能称交付；慢放用于诊断，不能替代正常速度。

当前只作路线评估与任务整理，尚未取得或验收新的完整人物底座，未采购/联系外部人员/替换正式资产。用户不需要先找供应方或学习绑定技术。下一次要求用户观看的应是通过内部表面检查的正常速度样段，而不是又一批失败草稿。

## 继续与淘汰标准

- 保留的是已验证有效的工具与数据，不保留失败绑定作为沉没成本。
- 新底座先过压力姿态再投入动作精修；不达标则更换或重做该资产，不追加装饰掩盖问题。
- 自然度无法由单一误差数值保证；内部检查通过后仍需正常速度视觉复核。
- 在质量门槛实际通过前，不预定发布版本、不勾选 P1 完成、不宣称已经修好。
