# 动作方向与参考筛选

更新：2026-11-11。用户主要参考石宇奇，允许综合其他选手；人物外貌和姓名不因此成为制作目标。

## 目标：有变化的专业动作

不能只制作“跑步、杀球、吊球”三个片段然后机械切换；也不能把完全随机的动作当成自由。拟采用以下分工，需样片证明：

1. **动作族**：准备与分腿启动、前场跨步、中场并步／交叉步、后场转身与到位、头顶击球、低点击球、落地恢复。每族保留合理的基本发力关系。
2. **情境参数**：来球高低与左右位置、身体朝向、到位程度、水平速度、支撑脚、准备时间、击球意图。用这些参数选取／混合基础动作，并在人体可行范围内调整。
3. **约束与过渡**：脚底不能随便滑，手握球拍，触球时刻与比赛一致；准备、加速、触球、随挥、恢复的时间关系明确。过渡需尽可能保持位置及速度连续，不能只对关节做硬切或过度平滑。
4. **不可行状态**：来球超出动作可覆盖范围时，不拉长肢体、不突然扭断肩腕；先记录现有判定与动画可达范围冲突，再决定是否需要独立 B 类玩法调整。

视频动捕只解决部分基础动作来源，不能替代游戏中的情境适配系统。一个固定视频不会自动覆盖任意来球。

## 第一批变化验证矩阵

不是要求每个格子都单独录制一个动作，而是用少量高质量基础动作证明可以合理适配。

| 轴 | 首批检查点 |
| --- | --- |
| 击球高度 | 低于肩、接近肩、高点击球；具体合法范围以游戏基线为准 |
| 左右位置 | 正手侧、身体前方、偏头顶／反手侧；不能将正手动作硬拉到不合理区域 |
| 到位状态 | 站稳、向前移动、侧向移动、后退后击球 |
| 时间 | 充分准备、较短准备；绝不为了完整播放视频而额外延迟按键 |
| 恢复 | 原地恢复、向中心回位、马上接下一次移动指令 |
| 视角 | 正常比赛镜头；正侧背慢放辅助 |

第一轮先选其中 6 个代表场景：站稳头顶杀球、后退到位杀球、横向移动后高远、前场跨步低点击球、急停后短准备击球、击球后立即反向回位。确认现有规则是否支持每个触发；不为凑场景擅自增加玩法。完整动作链通过后再扩大组合覆盖。

## 新方法调研后的选择

| 方法 | 能解决什么 | 当前取舍 |
| --- | --- | --- |
| MediaPipe | 从图片／视频估计人体关键点 | 本机 CPU 样例推理已通过；羽毛球的时序和遮挡未验证，只用作候选辅助 |
| SAM 3D Body | 单图全身网格与姿态恢复 | 新候选；官方主要任务是单图恢复，不等于稳定视频动作。安装依赖、权重访问、许可及本机 4GB 显存表现均未验证，不先大量下载 |
| Motion Matching | 根据姿态和目标从动作数据库检索合适片段 | 有足量高质量动作库后再评估；它不会凭空补出缺失的羽毛球动作 |
| Motion／Pose Warping | 按目标调整动作位置、方向或局部姿态 | 借鉴思路做轻量 Three.js 适配，不能直接把 Unreal 插件接到浏览器里 |
| Blender 关键帧与约束 | 修正动捕错误、补充拍面和支撑、制作缺失动作 | 保留为质量控制手段；不承诺 AI 初稿免修 |

来源：[MediaPipe](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker)、[SAM 3D Body 仓库](https://github.com/facebookresearch/sam-3d-body)、[安装依赖](https://github.com/facebookresearch/sam-3d-body/blob/main/INSTALL.md)、[Epic Motion Matching](https://dev.epicgames.com/documentation/unreal-engine/motion-matching-in-unreal-engine)、[Motion Warping](https://dev.epicgames.com/documentation/unreal-engine/motion-warping-in-unreal-engine)、[Pose Warping](https://dev.epicgames.com/documentation/unreal-engine/pose-warping-in-unreal-engine)。调研日期 2026-11-11；以上为方法依据，不是本游戏效果证据。

## 石宇奇参考入口

已找到官方 BWF TV 的 [Shi Yu Qi: A masterclass in badminton](https://www.youtube.com/watch?v=ygxmg78gna4)。已核实官方频道和视频说明；尚未完成逐帧动作分析，不虚构时间戳或宣称看完整段。首先用于风格／动作观察，未确认转播素材提取与再分发许可，不直接作为可发布动作数据集。

筛选顺序：全身可见的连续回合 → 正常速度的步法与回位 → 高远／杀球侧面慢放 → 低点跨步与恢复。避免只看集锦中的击球瞬间而忽略前后准备和支撑。

## 用户需要配合的最小事项

- 已提供：主要参考石宇奇；实际测试机为 iPhone 13；接受先桌面预览。
- 现在无需购买或安装任何软件，也无需先准备一大批素材。
- 可选：指出当前游戏最不自然的 1–2 个动作或给一段最喜欢的石宇奇片段；没有也能继续准备。
- 若后续确需自行拍摄：只在明确缺哪种动作后提供短拍摄清单。固定机位、全身脚底与球拍可见、光线充足、优先原始 60fps 及正常速度文件。双角度若不是同步拍摄，只能作为参考，不能当成多机位重建输入；用户不必为此买设备。
- 真机验收前再记录 iOS 版本。桌面预览不等于 iPhone 13 已通过。
