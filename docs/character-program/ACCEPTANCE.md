# 验收标准与证据规范

版本：2026-11-11，初始建议。数值性能门槛属于工程目标，尚未经过 iPhone 13 实测或用户对降档方案的确认。

## V：人物与动作

| ID | 检查 | 通过要求 |
| --- | --- | --- |
| V01 | 准备站姿、正常比赛距离、正侧背预览 | 运动员比例可信，角色配色可辨；无明显积木拼接、关节断开 |
| V02 | 准备、发球、高远、吊球、杀球 | 全身发力有先后，非持拍臂参与平衡；挥拍不断帧、不反折，随挥自然 |
| V03 | 前后左右移动、斜向移动、启动急停、回位 | 支撑与重心匹配；支撑脚不明显滑动，脚不穿地；头身朝向转换连贯 |
| V04 | 起跳杀球、落地恢复、移动中击球、连续出拍 | 正常速度可信，0.25 倍速可检查；无瞬移、异常拉伸、肩腕跳变或明显身体穿插 |
| V05 | 大幅抬臂、扭腰、跨步下蹲 | 肩腋、髋膝蒙皮保持体积；衣物与身体不出现明显穿模 |
| V06 | 同一击球族的来球高低、左右、移动到位和短准备变化 | 按 MOTION-DIRECTION 的代表场景检查，动作随情境有合理变化；不机械轮播、不任意随机、不靠肢体拉伸覆盖 |

每个动作至少记录正常速度比赛镜头和正／侧／背慢放。关键帧包含准备、引拍、加速、触球、随挥、恢复。正常速度观感与用户判断优先于单张截图好看。

## F：功能与回归

- F01：A 阶段相同输入的权威位置、球路、触球时刻、得分和规则结果不因视觉改变。
- F02：球拍触球帧与比赛权威 contact/contactAt 一致；记录世界坐标误差，沿用现有适用测试容差，不能随意放宽换取通过。
- F03：根位移只能由明确的权威来源负责，防止动画 root motion 与游戏移动重复叠加。不得拉长骨段弥补越界击球。
- F04：待机、移动、准备、击球、取消准备、落地、恢复之间过渡；短按、蓄力、快速连续操作都无额外故意等待。
- F05：暂停／恢复冻结与延续动作时钟；后台切回无时间跳跃导致异常姿态。
- F06：人机、两端好友对战、现有难度／扑救、普通与特殊赛后演出按最新版本回归。
- F07：加载失败可用、重复进入退出／角色重建资源释放、两个实例的骨骼／材质变化互不污染。
- F08：新版本预览服务重启与 SW 缓存版本核验；旧缓存升级与离线人机不受破坏。

验证分两层：骨段、触球时钟、克隆资源、网络与回退用行为测试；真实动作质量与手机操作用运行检查。为代码变化补充有意义回归，不为纯文档创建实现镜像式测试。

## P：iPhone 13

目标设备为标准 iPhone 13，不以 Pro 或更新机型代替。记录实际设备、iOS、Safari／主屏幕模式、横竖屏、质量档、亮度与低电量模式、测试时长、源码和资产指纹。系统版本尚未提供，不写作已验证兼容。

| ID | 场景 | 初始目标／判定 |
| --- | --- | --- |
| P01 | Safari 横屏完整比赛；主屏幕模式重复检查 | 首选 60fps 档；每个档位须记录持续性能，不用瞬时峰值表述流畅 |
| P02 | 普通对局和高强度连续回合各至少 10 分钟 | 60fps 档活跃比赛帧间隔中位数不高于 18ms、P95 不高于 25ms；加载／切后台单独统计，不能选择性删除卡顿 |
| P03 | 如果 60fps 目标无法达到 | 先调整阴影、像素比、材质开销与资产预算；30fps 档中位数不高于 35ms、P95 不高于 40ms 仅作为候选，需用户明确接受，不能偷偷降档 |
| P04 | 热稳定、内存、生命周期 | 不闪退、不出现页面被系统重载；连续进入退出 10 次不持续累积已知资源；记录主观发热及性能趋势，不冒充测得温度 |
| P05 | 实际触控与跨设备 | 摇杆和击球多指操作、横屏布局、暂停、前后台与好友同步正常；新旧同条件对照，不能用浏览器模拟替代真机手感 |

帧间隔指标需使用持续采样数据并记录分位数计算方法，浏览器 rAF 间隔不等于 GPU 渲染时间或精确触控延迟。若无法采集某指标，标为未测并说明替代证据，不能编造。

## E：后续可扩展性

- E01：同一人物更换至少一个独立服饰部件，不重做全部动作；持久化存储失败有合理回退。
- E02：至少两个外观不同、体型相近的人物复用同一动作库，握拍与脚底接地通过检查。
- E03：不同人物／衣物的资源 ID、骨架版本、单位、朝向、参考姿势、材质槽和绑定规范有记录；不使用脆弱的数组顺序作为长期协议。
- E04：默认换装／外观不改变数值与判定；体型变化是否影响玩法须单独决定。文件许可和来源完整。

CHAR-02 只做 E01／E02 的资产兼容性试验；完整界面、持久化和上线体验在 CHAR-05。

## 每轮证据包

每轮用阶段 ID＋递增试验号命名，包含：输入来源与许可、源码提交／脏状态、模型和动作 SHA256、工具版本／参数、复现命令、场景和机位、正常速度／慢放录像、测试输出、设备记录、未通过项和下一步。

状态统一使用：未开始／进行中／自动检查通过／待视觉验收／待真机／验收通过／已合并／已部署核验。不同状态不能合并成笼统“完成”。
