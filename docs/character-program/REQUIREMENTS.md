## 产品定义

“真实”指运动员的姿态、节奏、重心和动作衔接可信，不等于必须模拟人体所有肌肉。“舒展”不是无限放大关节角度；必须受人体关节、支撑关系和击球时刻约束。“自由度”区分视觉表现和游戏规则：本项目先升级视觉，后续再逐项讨论移动／跳跃／救球／击球的能力变化。

人物质量优先投入体态轮廓、关节变形、运动服轮廓、握拍与发力；面部近景、毛孔、复杂发丝和全身实时布料不作为第一阶段门槛。

## 建议采用的范围

- 保留 Three.js 浏览器游戏架构及已成立的比赛规则；现阶段不迁移 Unity／Unreal。
- 第一批一个基准运动员和一套运动服；两个比赛席位可复用该体系，保持辨识配色。
- 动作由可编辑片段与运行时修正共同驱动，制作阶段离线运行视频处理，不在玩家手机上运行 AI 动捕。
- 统一骨骼和资产规范；独立身体、发型、球衣、短裤与鞋。为衣物隐藏身体区域和有限体型适配预留数据。
- 暂不承诺任意体型、任意外部模型、所有服装可以自动适配；先在相近体型内证明复用。
- 不新增捏脸界面、商店、账号资产系统、付费装扮、随机匹配或与本任务无关的 UI 重做。

## 需要后续确认的节点

这些不阻止文档工作，不应一次性全部问用户。

1. CHAR-00：是否能安排实际 iPhone 13 测试、设备系统版本；没有设备时保留未验证状态，不能以桌面模拟通过代替。
2. CHAR-01：专业动作样片是否达到方向要求；可用视频不足时，再询问能否提供或拍摄有权使用的素材。
3. CHAR-02：基准人物体态／脸型及服装设计，用候选实物比较，不要求用户先选工具。
4. CHAR-04：真机难以同时达到视觉与性能目标时，明确展示取舍后确认。
5. CHAR-06：哪些新增运动能力应影响规则、操作与游戏平衡，逐项确认。

## 成功与终止标准

第一批成功：完整基本比赛中人物自然、操控及时，现有模式无回归；iPhone 13 真实测试通过约定性能档；资产可复现且可以做最小换装／换角色兼容试验。
