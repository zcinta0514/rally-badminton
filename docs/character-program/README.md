## 目标与边界

把 RALLY 的球员升级为写实比例、适度简化的专业运动员：动作自然、舒展且响应及时；先满足完整比赛，再增加服饰与不同人物，最后逐步扩展运动玩法。NBA 2K 手游是专业体育观感参考，不是素材来源或同等级交付承诺。

只使用现有 Codex 订阅、免费软件及许可适用的免费资源。不新增订阅、付费资产、插件、外包、云算力或硬件支出。最低目标设备为 iPhone 13；尚未通过真机性能验收。

## 工作节奏

1. 一次只推进一个可验收结果；长线任务按里程碑拆开，不做一个长期无法验收的大 PR。
2. 每轮结束更新 STATUS：具体完成项、失败项、证据、下一步、剩余决定。
3. 每次关键视觉迭代保留同机位、同动作、同速度的新旧对比。截图不代替动作录像。
4. 用户决定观感和玩法取舍；Codex 负责工具选择、实现、检查和解释证据。仅在费用、资料缺口、目标变更和最终体验验收时询问。
5. 不以安装成功、测试通过或导出 GLB 成功代替视觉与真机验收。
6. 按现有仓库规则完成独立分支、Draft PR、预览验收与合并授权。计划存在不代表获准发布。
