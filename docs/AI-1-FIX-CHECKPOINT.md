# AI-1 低体力进攻与长局恢复修正

2026-10-05；正式 main 基线 db8d453，v1.8.0。独立工作树 ai-1-low-stamina / fix/AI-1-low-stamina；根目录 P1 成果未修改。本候选尚未推送、合并或上线，游戏版本号保持 1.8.0。

## 最终规则

- 困难 AI 不再按杀球费用彻底排除杀球。保留原来高度、纵深机会判断和难度的反应／预测误差。
- 中等／困难候选在体力不足两次杀球成本时逐渐偏向低成本吊球。最大杀球评分扣 1.2、高远扣 .3，均不触及禁用阈值。入门选球比例保持原样。
- 每个真实得分回合后的下一次发球开始时，两侧各获得一次相当于自身基础恢复速率 × 2 秒的恢复量：均衡 10.8、灵巧 13、力量 7.6；不超体力上限。局间换局同样只计一次，最终比赛结束不补体力。
- 等待发球、分间计时及暂停不额外恢复，无法通过拖延刷体力；单个长回合的原有 .35 秒低强度恢复等待、消耗、速度／加速／控制疲劳惩罚全保留。已否决的连续回合恢复增强没有留在候选中。
- 规则说明同步显示双方每分恢复额度。运行协议 RULES_VERSION 由 3 改为 4，避免新旧恢复规则混用；这是兼容性标识，不是提前递增游戏发布版本。

## 前后对比

同种子、同来球：均衡困难 AI 满体力杀球 117/200（58.5%）不变；零体力从 0/200 到 48/200（24%），并非每个零体力来球都杀球。5400 个固定可达触点均请求并触球，疲劳移动速度下限未改。

同 20 种种子，每组 21 分单局，真实 UI 的陪练均衡型；玩家侧仍用同难度 AI 控制，因此只是可复现压力测试，不是人类实战采样。陪练低于 10% 体力的回合时间比例：

| 玩家侧打法 | 中等：之前 → 之后 | 困难：之前 → 之后 |
| --- | ---: | ---: |
| 均衡 | 34.5% → 0.2% | 65.2% → 22.5% |
| 灵巧 | 57.2% → 0.6% | 80.1% → 53.3% |
| 力量 | 22.3% → 0% | 62.6% → 2.4% |

入门陪练原本无明显枯竭，本组仍为 0%。困难均衡实际低体力非发球杀球占比从 7/568（1.2%）升至 25/436（5.7%）；固定触点的选杀比例不能直接当作实战比例。

真实人机配置 180 场均在 600 秒模拟上限内结束。对称角色压力测试另 180 场中，178 场在上限内结束；双灵巧 medium seed11 与 hard seed6 延长观察后分别在 733.45／665.6 秒结束，不是规则死锁。总计 360 场均实际结束；长 AI 对 AI 回合不代表手机帧率或用户实战体验通过。低体力仍会发生，尤其灵巧侧持续施压时，方案目标是缩短持续枯竭并保留机会进攻，不是消灭体力取舍。
