# FX-3：分级赛事灯光与游戏内设置

这是任务规格。当前进度、失败、分支和下一步只维护在 [PROJECT-STATUS](../PROJECT-STATUS.md)，本文不另建实时进度表，不预定发布版本号。

## 目标、范围与依赖

- 对应 [开发计划](../DEVELOPMENT-PLAN.md) FX-3、P3-5、P5-3／P5-4。继承 FX-1／FX-2 的共享状态、事件等级与个人混音设置，记录实际依赖提交。
- 目标：得分等级可从灯光、观众和声音共同感知；玩家在游戏中看清实际角色、难度、辅助和计分规则，并即时调整个人声光。
- 用户选择分级赛事效果，只完善现有设置；不增加休闲／竞技模式、段位、匹配或排位服务，不改变计分、人物动作和球路。

## 灯光表现与生命周期

| 事件 | 默认表现 | 最长时长 |
| --- | --- | --- |
| 普通赢分 | 获胜侧灯带柔和亮起后回落 | 0.6 秒 |
| 精彩分 | 灯带两次短促脉冲 | 1.2 秒 |
| 局胜 | 获胜侧向外围扩散亮起 | 2 秒 |
| 赛胜 | 全馆分区扫光 | 3 秒 |

- 分级优先序为赛胜＞局胜＞精彩分＞普通分，每次得分只启动一个最高级效果。复用 FX-2 的事件等级；不能从画面估计比分或额外判定精彩分。
- 主照明、球和球线保持可读，效果主要作用于馆内灯带与外围区域；不做全屏白闪，不增加比赛等待。下一次发球立即恢复基础照明。
- 用统一表现时钟驱动灯光和观众；最终得分后比赛时间冻结时仍可完成赛胜表现。暂停、隐藏、离场、断线和重赛清理效果，恢复不补播过期事件；同一比赛事件只启动一次。
- 提供完整／柔和／关闭三档；首次默认完整，系统减少动态效果时默认柔和，用户明确选择后遵循用户设置。柔和档使用单次缓慢亮度／色彩变化，不做短促闪动。

## 比赛与个人设置

- 开局前用真实 ROLES 数据比较速度、力量、体力上限、恢复和耗费；难度说明对应实际 AI 反应／线路节奏与入门辅助，不仅改名称。
- 快赛与标准计分显示局制、目标分、净胜要求和封顶规则，涵盖加分状态。保留现有角色、难度、入门辅助和规则的关系，不新增游戏模式。
- 游戏内提供不遮挡主要球场的小型设置面板。角色、难度、计分与辅助在对局中只读，改动用于下一场；显示实际权威规则，联机不显示未生效的个人菜单选择。
- 总音量及击球／移动／观众／环境音量、灯效立即生效并保存本机。沿用现有暂停机制，打开设置不自动暂停；面板操作不意外触发移动／挥拍，继续球场操作时关闭面板。
- 新偏好采用归一化读取与安全默认值，纳入更新偏好恢复；本机声光选择不改变对手规则、体力或判定。
