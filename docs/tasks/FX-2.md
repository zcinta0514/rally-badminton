# FX-2：真实场上声音与观众互动

这是任务规格。当前进度、素材缺口、分支和下一步只维护在 [PROJECT-STATUS](../PROJECT-STATUS.md)，本文不另建实时进度表，不预定发布版本号。

## 目标、范围与依赖

- 对应 [开发计划](../DEVELOPMENT-PLAN.md) FX-2、P2-6、P4-1／P4-3／P4-5、P5-3／P5-4。依赖 FX-1 的有效事件与联机边界；分支须记录实际继承提交。
- 当前高远与吊球共用击球素材，杀球来自同一录音中较响一击，移动只有一种脚步，观众仅普通掌声／精彩分欢呼。目标是声音与实际发力、位置和回合情绪一致。
- 用户明确只优化声音，不借此重做人物动作或扩展球种。现有真实录音可作基线；新增素材须有来源与使用许可，授权外部录制和实际消费依具体会话授权，不由本任务卡增加。

## 素材与声音设计

- 为当前实际存在的发球、高远、吊球、杀球分别准备真实录音，每类至少四个有效变体；依据实际动作和发力审听，不能用同一剪辑的音量／变调冒充独立动作录音。尚未实现的平抽、挡网等不冒称已接入。
- 补齐移动脚步、急停摩擦、起跳落地、挥拍、球落地与触网。依据实际位移、接地及动作阶段触发；重复快照、滞后帧和位置重置不产生额外脚步。
- 观众包括低响度环境、长回合期待、普通掌声、精彩分欢呼、局胜和赛胜；在回合 8 拍、12 拍逐级增强期待，得分后释放。观众声音与现有观众动作使用同一等级。
- 普通失误得分采用克制反应；合法制胜杀球或八拍以上制胜沿用精彩分条件，局胜和赛胜优先。局点／赛点依据实际计分逻辑，覆盖加分和封顶，不按页面文字推测。
- 制作本地素材清单：原件来源、许可、哈希、裁剪／处理步骤和输出；缺素材明确保留缺口。发布素材与原始录音分开，原始文件继续不进入公开服务。

## 音频系统与事件接口

- 扩展现有 Web Audio 和单个 AudioContext，提供击球、移动、观众、环境混音通道；默认总音量沿用 60%，通道默认击球 100%、移动 65%、观众 50%、环境 15%，素材先统一审听与标定。保留原静音开关及赛后语音生命周期。
- 相对实际镜头呈现左右和远近感，手机扬声器与耳机均验收；复用 Web Audio 空间声场，不引入第二套音频上下文。
- 击球优先，观众与环境自动让出响度；限制并发声源并清理节点，优先保留即时触球，低优先级氛围先淘汰。变体按事件稳定选择，避免机械相邻重复。
- lastShotInfo 补充 serving、contact 和 charge；共享结果记录区分普通分、精彩分、局胜、赛胜。仅消费已确认触球／碰撞与动作阶段，不按按钮按下预测播击球声。
- 按比赛编号、hitId／pointId／actionId 去重。暂停、隐藏、断线、重连、重赛和静音正确清理；恢复后不补播过期音效。加载或解码失败不能中断比赛，不排队等待素材后追播旧事件。
- 新素材注册进入 PWA 资源清单，支持子路径和离线；旧素材包大小及文件名断言按真实新清单更新，保留来源、许可、MIME、原件私有和离线完整性验证。

## 验收、参考与回退

- 验证各动作、弱触球／强发力、近远位置、长回合、普通失误、精彩分、局胜／赛胜及重复／乱序快照；连续平抽场景不得漏播或叠音失控，旧动作缺口仍独立记录。
- 相关入口：node --test tests/audio.test.js tests/audio-assets.test.js tests/crowd.test.js tests/connection-recovery.test.js；最终候选执行 npm test 与 npm run build。
- 两款目标手机连续对打至少 30 分钟，听辨不同动作与器材声音，验证声场、混音、Safari 音频中断恢复、静音和离线。素材、听感、互动及 60 帧目标分别验收，不以单元测试替代用户听觉验收。
- 参考已读取的 [Three.js PositionalAudio](https://github.com/mrdoob/three.js/blob/r185/src/audio/PositionalAudio.js)、[Howler v2.2.4](https://github.com/goldfire/howler.js/tree/v2.2.4)与[篮球场上音效模块](https://github.com/mike007jd/vibebasketball/blob/184a5b27ee259869744f0b32de9954ab7983c1bb/src/game/courtSfx.js)。参考其事件、空间声场和手机恢复机制，不采用篮球合成音替代真实羽毛球素材。
- 证据逐步写入独立检查点并链接 PROJECT-STATUS；回退到已保存素材与音频入口，比赛状态和默认人物不受回退影响。Issue／PR 尚未建立。
