# UI-3 开始比赛下方横线与比赛内顶栏控件对齐

2026-11-01 用户验收 1.12.0 后提出两处界面缺陷：进入「人机对战」后，「开始比赛」按钮下方有一条突兀的横线；进入比赛后，右上角一排按键与其上的图标（声波、问号）对得不准，看起来怪。要求先单独开一条 PR，不合入，等用户实测效果再决定。

## 缺陷与处理

**1. 「开始比赛」按钮正下方的横线**

实测 `#start-ai-confirm` 底边 y=699，`#install-app`（主屏幕版入口，`src/pwa.css` 里带 `border-top: 1px solid`）top 也是 699，两元素零间距相接。1px 线正好压在按钮 13px 圆角的下沿外侧，在按钮两端露出，读起来像按钮多出来的一条下划线。

处理：只在人机对战入口页隐藏该分隔线的颜色，不改边距、不改高度、不移动任何元素。

```css
#menu[data-entry="ai"] > #install-app { border-top-color: transparent; }
```

首页保留原分隔线（那里是真正的分区，与按钮之间有大段留白），训练页与好友页不受影响。

**2. 比赛内右上角控件对不齐**

实测（1280×800，`data-screen=match`）：`#camera-toggle`（视角）高 32px，`.icon-btn`（声音／全屏／问号／暂停）高 36px，`.palette-toggle`、`.match-settings-toggle`（配色／设置）被拉伸到 36px。同一行三种高度，视角按钮上下各差 2px。

图标本身：三个 `.icon-btn` 的墨迹中心都落在 cy=30（完全居中），但**声波图标墨迹只有 12.25px 高**，全屏括号与问号是 15.25px —— 三个同尺寸按钮里的图标视觉大小不一致，看起来"对不准"。

处理：
- `body[data-screen=match] .camera-toggle` 的 `min-height` 由 32px 提到 36px，与同行控件同高；竖屏／矮屏断点本来就是 30px，保持。
- 重画声音图标路径，把墨迹从 12.25×15.25px 放大到 14.75×15.25px，与全屏括号、问号一致；同时保持原有 1.8 描边与听筒／声波／静音叉的造型。改后三个图标墨迹中心同为 cy=18.38（按钮内），水平偏差 ≤0.4px。
- 竖屏（`orientation:portrait`）下把「配色」色点隐藏、两个文字胶囊内边距收到 6px，并强制单行，避免 390px 宽时"配色"/"设置"被挤成两行（原状为 44px 高，比邻居高 14px）。
- 窄竖屏（≤400px 且竖屏）隐藏品牌文字、控件降到 28px：320px 宽时原状右侧按键被裁掉，改后整排正好收进安全区。

## 顺带修正

比赛内品牌文字原为 `#122b25`（纸白主题的品牌色），压在深色球场上几乎不可见。改为纸白 `var(--surface)`，`RALLY` 小字沿用主线的浅绿。该项不在用户原始描述内，可在实测时单独否决。
