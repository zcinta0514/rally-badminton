# FX-4：地胶配色可选与独立入口

这是任务规格。当前进度、失败、分支和下一步只维护在 [PROJECT-STATUS](../PROJECT-STATUS.md)，本文件不另建实时进度表，不预定发布版本号。

## 目标、范围与依赖

- 对应计划：独立编号 FX-4（不属现有 FX-1～FX-3 范围）；复用 FX-3 的局内设置面板与偏好存储基础。关联 P5-3／P5-4 的观赛与个人设置方向。
- 问题：球场只有单一深绿配色（`0x0c7054`），玩家无法像真实球馆那样选择紫罗兰、玫粉、赛事蓝地胶。
- 目标：比赛中可从右上角独立「配色」入口切换四套地胶配色，即时生效、本机保存、重进游戏保留；入口不再藏在设置面板内。
- 范围：本任务改动配色定义、场馆运行时换色、本机偏好字段、独立入口 UI 与其测试。不新增比赛规则、不改计分／动作／球路／联机权威、不改音效、不发布版本号。
- 依赖：基线为联网核验的 `origin/main` `dcf0532`（v1.9.0 发布文档合并）。参考来源：2024 巴黎奥运会 La Chapelle 场馆照片（紫色区域取样）、地胶行业把 purple／pink 列为标准可选色的公开资料。

## 配色与实现边界

| 配色 | 参考 | 地胶（court） | 外场（apron） |
| --- | --- | --- | --- |
| 经典绿 | 现有默认，不改 | `0x0c7054` | `0x1c4248` |
| 赛事蓝 | BWF 赛事主流蓝 | `0x154473` | `0x1e324a` |
| 紫罗兰 | 2024 巴黎奥运紫调 | `0x73589e` | `0x483861` |
| 玫瑰粉 | 商业球馆浅玫粉 | `0xa14d72` | `0x633449` |

- 四套配色移动同一组地板层次：地胶、外场、场边 accent、底座；场馆背景／雾色／白色球场线不变，白线对每套地胶的对比度不低于 4.5:1。
- 未知名回退经典绿；旧存档（无该字段）仍打开经典绿；未知字段与损坏 JSON 不阻塞启动。
- 配色只影响本机画面，不上传、不改变对手视角、不影响判定与联机协议。
- 独立入口：比赛屏右上角「配色」按钮（圆点显示当前颜色）+ 浮层色块选择；设置面板内的配色下拉移除，避免双入口。面板保持打开方便连续对比，点击外部或结束比赛关闭。

## 验收、证据与回退

- 覆盖四种配色切换即时生效、localStorage 立即落盘、刷新后保留、未知名回退绿、旧存档兼容、白线对比度、地板亮度阶梯、四色色相区分、面板开关与键盘 Escape、外部点击不误关。
- 固定命令：`node --test tests/court-palettes.test.js tests/arena-preferences.test.js tests/view-court-palette.test.js tests/palette-picker.test.js tests/update-preferences.test.js tests/connection-recovery.test.js`；最终候选执行 `npm test` 与 `npm run build`。
- 视觉证据：`node scripts/capture-fx4-palettes.mjs --out artifacts/fx4/<new-directory>` 实机切换四色截图、设置入口截图与 reload 持久化核验；截图与 `report.json` 落在被忽略的 `artifacts/`，检查点记录摘要与文件哈希。
- 需要用户实际查看的内容：四套配色观感、独立入口位置与操作、是否再调深浅；真机 30 分钟／稳定 60 帧由用户自理。
- 回退：入口与配色均无存档写入以外的副作用；恢复默认可在设置面板「恢复默认」或清除 `rally.arena.v1`；移除本任务提交即回到单一绿色球场，旧存档因字段未知自动回退，不影响联机。
- Issue／PR：分支 `feat/FX-4-court-colors`；PR 建立后回填链接。
