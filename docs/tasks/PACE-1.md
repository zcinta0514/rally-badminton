# PACE-1 球路节奏与接球响应

用户已批准顺序：先统一球路节奏，再调移动和接球容错。交付独立分支与侧边栏可玩候选，用户亲测通过后再合并。

基线：2026-10-23 联网核对 origin/main = 01fed373（含已发布 v1.10.0）。目录 `.cindy-worktrees/vibrant-thompson`，分支 `cindy/vibrant-thompson`。原项目及 swift-hamilton 人物在制成果不整合、不写入；此任务无人物依赖。发布版本保持1.10.0。

## 范围

- 量测发高远、回合高远的初速、顶点、落点和飞行时间，再调整真实共享出球解算。
- 量测移动起步、反向与制动；优先改善响应衔接，保留角色速度、体力差异。
- 检查提前输入、快速来球与低位救球；有限容错仍受半场、空间范围、冷却与触点质量限制。
- 对应开发计划 P0 场景与 P2/P3 击球、移动、回位验收；不把整个人物计划标为完成。

## 验收

固定相同输入场景比较修前后：发高远、回合高远、后场调动后上网接吊球、合理站位接杀球。记录没赶到与到位却漏接，早输入正确站位能接，迟判失位仍丢分，勉强救球不变成高质量反攻。跑共享规则、单机AI、联机兼容与输入测试及完整测试构建；浏览器中实玩并核对当前服务快照、资源指纹、缓存和既有配色功能。手机触控自动化只验证链路，真机手感待用户确认。

预期仅修改 `shared/game.js`（物理与响应）、必要的 `src/main.js`（及时提示）、新增场景脚本与针对性测试，以及任务卡、当前状态、检查点和机器QA。发现需增加模块时先复核范围。
