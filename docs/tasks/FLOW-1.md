# FLOW-1：完整工作流与跨电脑接续备份

用户于 2026-11-09 要求上传本项目完整工作流，并明确包含大型制作源、原始参考和视频证据，确保其他电脑可继续人物制作。

## 范围

- 从实时核验的最新主线建立流程分支，保留最新玩法、杀球与球网功能。
- 上传协作规则、开发计划、任务模板、PR 模板及新窗口入口。
- 交接校验支持跨电脑的相对目录，并允许显式重新绑定目录／分支；不修改历史基线、任务目标或授权。
- 原工作目录和各有效 worktree 做只读、按内容去重的快照；包括未提交、未跟踪和 ignored 的制作资源，另带完整 Git bundle。
- 分块资源放在同仓库专用备份 Release，附逐文件哈希、分块校验和、恢复工具和命令。
- 依赖安装目录、缓存、构建输出、密钥及玩家运行数据不上传；排除项记录在清单中。

## 验收

- 主线游戏测试与构建；交接目录迁移、分支错配、错误基线回归。
- 小型双 worktree 端到端恢复：未提交修改、删除文件、ignored 源文件、去重、相对链接及损坏分块拒绝。
- 完整备份在上传前解压回读，验证每个源对象 SHA256。
- 上传后逐附件核对名称、字节数和服务端 digest；另从仓库重新 clone 检查工作流文件与交接。
- 已知未验收的人物质量继续保留原有口径；备份成功不等于人物或正式版本验收。

## 边界

本任务不合并旧人物实验到 main，不替换正式人物，不递增游戏版本，不重新部署生产站点。专用备份标签属于资料快照，不是游戏发布版本。
