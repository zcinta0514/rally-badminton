# Match entrance and shadow implementation plan

**Goal:** 实现用户指定的候场视角抬升、聚光灯收拢和自然人物/羽毛球阴影。

**Architecture:** 独立的展示时钟与摄像机插值；单人计时在入场时冻结，联机只占用既有准备倒计时，权威比赛开始时立即结束展示。主光真实投影配合柔和接触阴影，不改变球的位置、碰撞或选手动作。

**Tech stack:** Three.js、现有游戏主循环、Node tests、Chromium 手机模拟。

基线：52b9ebf 已包含远端 main 97a129b；继续用户反馈对应 Draft PR #33。保留独立人物工作目录。用户已指定效果并授权继续加强，无新增审批步骤。

- [x] `src/match-entrance.js`：约1.8秒展示、隐藏页面冻结、减少动态效果跳过、联机截止保护；镜头沿球场外弧抬升，落到当前玩家选择的比赛机位。
- [x] `src/view.js`：从实际候场镜头取得起点；两盏顶灯从边侧平滑转向半场，亮度与射束角度稳定收敛；HUD在入场结束后显示，退出菜单取消展示。
- [x] `src/main.js`：单人计时与输入保护；联机不修改协议、计时和开赛时刻；进入活跃比赛/断线恢复时不播放挡住操作的动画。
- [x] `src/contact-shadow.js`、`src/athlete.js`：软边身体与双脚接触阴影，脚抬离地面时减弱；羽毛球阴影随高度扩散、变淡并沿主光投影方向偏移。保留现有预测落点标记的区别。
