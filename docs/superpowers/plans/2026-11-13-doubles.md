# Doubles Implementation Plan

> **For agentic workers:** Use subagent-driven-development for implementation and independent spec/quality review. User approved production on 2026-11-13; no repeated design approval required.

**Goal:** Deliver one-human/three-AI and four-human doubles with free positioning, meaningful teammate interference and consistent authority.

**Architecture:** Keep team identity separate from player slots. Extend the shared simulation without changing singles defaults, then adapt the transport and presentation. Doubles-only helper modules own formations and collision where appropriate.

**Tech Stack:** JavaScript ES modules, Three.js, PeerJS, node:test, browser mobile emulation.
