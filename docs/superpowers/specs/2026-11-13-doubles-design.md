# 双打设计（用户已批准制作）

## 范围
自由跑位、辅助配合，保留抢球、让球失败和站位失误。人机为本机一人固定控制一个角色加三 AI；联机为四真人两队。允许重复角色，队友难度独立于两名对手。首版只支持普通对局，不支持混合补 AI、房主迁移或特殊赛后表演。保留单打所有功能。

## 规则与标识
比赛 format 为 singles/doubles。球员 slot 独立于 team：双打 slots 0、2 属于队 0，1、3 属于队 1，单打保留 0、1。score/server/winner/lastHit 仍表示队伍，新增 serverPlayer、receiverPlayer、lastHitPlayer。四名球员独立体力、动作、输入、角色。
双打半宽 3.05 米，回合底线沿用 6.7 米，发球后界 5.94 米，短发球线 1.98 米。同一方连续得分由同一发球人交替左右发球；接发方得分后按该队当前左右发球区及得分奇偶确定新发球人。接发球只能由指定接发者触球，随后自由接球；不能同队连续击球。局间按现有标准赛制换边并明确下一局初始发接球位置。

## 配合与碰撞
AI 联合选择主接者和补位者，考虑到达时间、有效触球机会与移动；有反应延迟、承诺保持和失去接球机会后的交接。真人在有效范围准备出拍会影响让球判断，远处按键不能强迫 AI 放弃。进攻前后、防守左右、队友拉边补中；不强制真人换位。AI 只能观察当前输入和场上状态。不中途读未来输入、不瞬移、不随机故意弃球。
同队身体轻度分离，保留切向移动，不能互相穿过、无限推动或卡死；没有伤害、摔倒、击飞。碰撞不直接判罚，但影响位置与接球机会。首次有效触球只结算一次，竞争依据权威模拟接触时刻与实际距离；完全相等时采用轮转优先，不能固定偏袒房主。

## 联机与界面
四位置大厅，选队、选角、确认规则，变更取消准备。全员准备后倒数。房主权威模拟，三个连接分发状态；每个玩家通过本人 slot 提交输入，镜头按 team 定向，名字、颜色和本机标记区分四人。沿用现有按钮，增加少量配合提示。单打双打战绩分开。
断线暂停，30 秒恢复原身份、位置和角色；超时中断不计胜负。不自动替补。房主进程仍在且连接恢复时允许重连；房主进程销毁无法迁移，超时结束。重连身份使用会话凭据，不允许仅凭昵称接管位置。

## 验收
规则测试覆盖四 slot、发接球轮转、边界、换边、同时挥拍、漏球补救、碰撞与 AI 补位。联机覆盖四人准备、满房、输入隔离、断线恢复与超时、再战、消息校验。浏览器验证常见与较矮手机横屏和竖屏、实际人机回合和四客户端；记录模拟与真机区别。npm test 和 npm run build 通过后开 Draft PR 并提供实际分支预览。用户验收后另行申请合并，不直接部署。
