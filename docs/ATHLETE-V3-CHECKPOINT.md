## 剩余质量门槛

1. 当前人物为**纯色、静立、零动画片段**的阶段模型。贴头短发、首轮球鞋、无衣物动态褶皱和专门装备细节，不能与 2K 类运动手游完成品等同；本轮保留了贴合头部的短发壳及眉眼唇细节，但额前发带和独立 V 领带因侧视悬浮/穿插已撤出 GLB。先按正面、90°侧面、背面及用户提供的可授权图片校准脸和头身比例，再做细节塑形及材质，不能以顶点数代替视觉验收。
2. 当前为 52 个变形骨：20 个原基础骨、双侧前臂扭转骨，以及双手各 5 指 × 3 节指骨。指骨与前臂扭转已有独立权重和变形回归测试，但**趾骨、完成握拍姿态、击球锚点、鞋底约束和完整独立动作仍未建成**。自动测试不能证明真实姿态或可用于比赛。独立的 src/athlete-v3-lunge-draft.js 是据已实看的前场片段原创编排的动作实验：首尾可恢复原始姿态、落脚期脚踝坐标暂时锁定；但目视仍有躯干、伸拍及衣物穿模问题，**不得开放为已完成动作**。
3. [照片参考](ATHLETE-V3-REFERENCES.md)逐张记录来源与观察局限；[动作参考](ATHLETE-V3-MOTION-REFERENCES.md)严格分开实际看过的视频帧与依据研究拟定的动作节奏。若不能连续观看画面就不标造假的时间戳。用户自有成年人三视图或握拍手、鞋子近景有助于提高质量，但不是当前静态模型启动的先决条件。
4. 后续需重新画准备、垫步、移动、杀球、高远球、吊球、跨步及回位，保证支撑脚不滑、拍面/手与已有比赛触球事件对齐，随后检查新球/网的场地尺度、球的朝向、碰撞和手机实际帧率，才可考虑替换正式比赛资产。球/网目前不接入比赛与侧边栏交互。

全程只用免费本地工具和经核许可的素材；除用户已有 Token 费用外不新增付费路径。侧边栏是本地预览，不代表源码已推送或线上已部署。
