# RALLY V4 人物全量重制计划｜2026-09-18

## 决策

用户已确认采用 C：全量重制。V3 不再作为新人物的几何基线；它只保留为对照、接口和 QA 参考。正式比赛继续使用 \`src/models/athlete.glb\`，V4 在独立预览和独立文件名下推进。

## GitHub 调研结论

外部项目只借工作流，不复制代码、数据库、角色资产或提示词内容：

- CharMorph、MPFB2：参数化人体、形变、服装/发型拟合和 headless Blender 流程有参考价值；代码/部分数据许可边界不适合直接进入本 MIT 仓库。
- Elastic-Clothing-Fit：proxy 拟合、局部顶点组、距离衰减、凹面 hull、UV 保持和可视预览与本项目问题高度相关；GPL-3，只借机制。
- AndoSim：研究型布料/壳体求解器；MIT，但当前 Blender 5.2 需要单独编译验证，不作为 V4 第一阶段依赖。
- awesome-astra-blender-characters：九视图、脸发流程和视觉 QA 结构可借鉴；不把其 skill、参考图或第三方素材当作人物生成器。
- CharacterStudio、VRM-Addon-for-Blender：GLB/VRM 导出、Humanoid 映射、材质合并和回读验证可参考；不把 VRM 骨架合同替代 RALLY 比赛语义骨架。

## 阶段与可交付物

### 0. Blockout（当前阶段）

新建独立 V4 工程和静态 GLB，只验证虚构运动员的身高、头身比、肩宽、腰胯比、四肢长度、手脚尺度和静止站姿。先不加入服装细节、发丝、动作和比赛接入。

交付：

- \`artifacts/model-workbench/athlete-v4-blockout.blend\`
- \`src/models/athlete-v4-blockout.glb\`
- 正面、三分之四、90°侧面、背面、俯视肩胯检查图
- Blockout 测量报告和未通过项

进入阶段 1 的门槛：五视图轮廓无比例跳变；头、肩、髋、膝、踝、手掌、鞋底在同一尺度合同内；没有把旧 V3 的服装/头发几何混入；静态 GLB 可被 Three.js 读取且无动画。

### 1. 人体与面部

在 Blockout 签字后重做人脸、手掌、握拍手、脚趾/脚底和肩髋膝踝过渡。建立骨架前先完成左右对称、局部细节和三分之四视角检查。

### 2. 服装与鞋

从 V4 人体重新建立球衣、短裤和球鞋独立拓扑。优先处理肩袖+yoke、领口、腋下、裆部、腿口、鞋袜接缝；不沿用 V3 的 fitted shell，也不沿用 V3 的单边袖口绑定 bug。

### 3. 绑定与接口

重新放置骨骼、bone roll、权重和扭转；建立 分层变形骨架到正式 18 个语义骨（另加角色根变换）的显式映射。先做静态姿态回归，再做握拍和脚底约束。

### 4. 动作与运行时

按准备、分腿垫步、前场弓步、头顶击球、杀球/高远球、回位六类动作逐段制作。逐动作做四视角检查、触球帧检查、支撑脚滑移检查和移动端性能检查。未完成这些检查，不替换正式比赛人物。

## 参考项目的使用边界

V4 全部实现继续使用本项目自研 Python/Bpy 和 MIT 兼容依赖。GPL/AGPL 项目只记录设计思想和问题分析，不复制实现；所有输入素材继续使用已核验的 CC0 来源或项目自有几何。
