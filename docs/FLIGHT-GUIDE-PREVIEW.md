# 球路虚线预览 1.19.0

基线：GitHub API 核验 main 为 e8b74bbfbb749f1c83546a914b8e88692dc6bcf9。独立 codex/flight-guides 分支；音效候选尚未合并，保持独立。

来球使用青色短弧线（最多未来 0.65 秒），按住击球键在可触球或预计可达时切到粉色意图轨迹。预计触点从共享拦截建议获取；球种、拖动和蓄力驱动弧线；松手、出球、得分、换边与退出时清除。暂停冻结，幻影消散前暂不揭示真球预测。既有落点圈与风险圈保留，真实击球质量及联机协议不变。

渲染为一个固定容量的 LineSegments，按世界距离分割虚线，尾端减弱，出现淡入。全轨迹使用共享重力/阻力采样；来球包含擦网变化。粉线表达意图，无法承诺玩家真的到达预计触点。

验证：
- 最终相关自动检查 43/43 通过，覆盖双方、发球/来球、提前按键、松手、暂停/换边、幻影、网络回放、擦网与资源释放。
- 全量检查（新增渲染测试前）813 项，806 通过，7 失败；失败均为 project-handoff 的 Windows 路径或 symlink EPERM，在未改动基线上同一组 7 项已复现。
- 最终构建 b196d346c5cf7e80，122 个本地资源。
- scripts/verify-flight-guide.mjs：844×390 和 568×320，实际按住、拖动和松手发球；固定来球画面中验证青线以及高远/吊球/杀球粉线。无页面异常，无横向溢出；检查了截屏。使用 Windows Chrome 手机触控模拟，非真机。固定来球通过仅测试页面的 CourtView 包装注入，产品代码不含注入入口。
- 本机实际预览服务器 http://127.0.0.1:3345/，脚本针对该服务器校验构建标识并重跑。

验收：进入单人对战，按住高远球键并拖动，观察粉线；松手发球，等待对手回球出现青线。重点判断可读性、预测长度、切换时机和蓄力拖动是否自然。预览等待体验反馈，不自动合并或发布。
