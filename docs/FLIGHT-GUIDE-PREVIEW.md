# 球路虚线发布检查 1.20.0

基线：合并前主线更新至 12f1f721df00288abb22e856215430e0450433d3（1.19.0 音乐更新）。已整合该提交并保留赛事歌单、切歌、按键音效与 MP3 离线范围请求；球路版本递增至 1.20.0。

来球使用青色短弧线（最多未来 0.65 秒），按住击球键在可触球或预计可达时切到粉色意图轨迹。预计触点从共享拦截建议获取；球种、拖动和蓄力驱动弧线；松手、出球、得分、换边与退出时清除。暂停冻结，幻影消散前暂不揭示真球预测。既有落点圈与风险圈保留，真实击球质量及联机协议不变。

渲染为一个固定容量的 LineSegments，按世界距离分割虚线，尾端减弱，出现淡入。全轨迹使用共享重力/阻力采样；来球包含擦网变化。粉线表达意图，无法承诺玩家真的到达预计触点。

验证：
- 整合后相关组合自动检查 66/66 通过，覆盖双方、发球/来球、提前按键、松手、暂停/换边、幻影、网络回放、擦网与资源释放。
- 整合后本机全量检查 817 项，810 通过，7 失败；失败均为 project-handoff 的 Windows 路径或 symlink EPERM，在未改动基线上同一组 7 项已复现。
- 最终构建 ecc530592a33175d，130 个本地资源。
- scripts/verify-flight-guide.mjs：844×390 和 568×320，实际按住、拖动和松手发球；固定来球画面中验证青线以及高远/吊球/杀球粉线。无页面异常，无横向溢出；检查了截屏。使用 Windows Chrome 手机触控模拟，非真机。固定来球通过仅测试页面的 CourtView 包装注入，产品代码不含注入入口。
- 本机实际预览服务器 http://127.0.0.1:3346/，脚本针对该服务器校验构建标识并重跑。

验收：进入单人对战，按住高远球键并拖动，观察粉线；松手发球，等待对手回球出现青线。重点判断可读性、预测长度、切换时机和蓄力拖动是否自然。用户于本聊天授权「测试好了再合并」。保留预览供复查，合并前等待新提交的 Linux CI 全量通过，合并后单独核验两处线上部署。
