# 自动更新修复（1.21.6）

## 原因与行为

1.21.2、1.21.3、1.21.4 的更新协调代码一致。旧协调器要求所有游戏窗口同意；后台休眠或正在对局的窗口会否决其他空闲窗口的更新。另有等待版本阻断后续检查、初始化遗漏已完成控制器切换的问题。

新版只让安全空闲窗口参加刷新事务；其他窗口必须已有可验证的旧版本缓存绑定，才能保留旧资源继续运行。未知版本、缺失版本缓存仍阻止接管。旧对局回到首页后再更新。首次安装不强制接管，缓存版本隔离、保留策略、刷新循环保护继续有效。

## 验证

- 全量测试 860 项通过；之后补充的两项安全边界测试及全部 33 项 worker 测试通过。
- `npm run build`、`git diff --check` 通过。
- `scripts/verify-auto-update.mjs` 使用真实 1.21.4 快照与当前构建模拟部署切换，验证并行旧对局、首页升级、旧对局退出后升级、离线重开。
- 浏览器环境：Windows Chromium，手机横屏 844×390、667×375；不代表 iOS 真机验证。

运行浏览器验证前准备 1.21.4 checkout（2fbcb23）及其 npm 依赖；设置 `RALLY_OLD_ROOT` 指向该目录。安装 Playwright 后执行 `node scripts/verify-auto-update.mjs`；可通过 `RALLY_BROWSER_PATH` 指定 Chromium。报告和截图输出到 `artifacts/auto-update/`。测试通过按钮的 DOM click 进入对局，聚焦更新状态迁移，不作为触屏输入性能测试。

## 用户侧边界

联网、回到游戏首页并停止操作后才应用更新。离线时无法下载新版；未识别的更老窗口仍需关闭后重开。浏览器/CDN检查与下载也需要时间，不能承诺每台设备在发布瞬间更新。
