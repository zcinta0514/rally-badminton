## R3：主流游戏式主菜单与竖屏 PWA 安全区

2026-10-31。用户反馈首屏“羽毛球单打”像分类名、“选择对战模式，开始比赛”不够正式，要求参考主流游戏的主菜单语言、字体和格式；同时竖屏添加到主屏幕后底部出现黑条、顶部被状态栏遮住。基线仍为 7164832c，分支不变，版本号未改。

### 主菜单

- 标题区改成“眉线小字 + 品牌 + 单项 + 赛制元信息”的游戏主菜单结构：`BADMINTON` / `开拍 RALLY` / `单打 SINGLES` / `1V1 · 5 / 11 / 21 分 · 对角发球`。不再用“羽毛球单打”这种分类式标题，也不用“选择对战模式，开始比赛”这类整句指令。
- 参考主流体育游戏的做法，英文标签只做字距处理（0.22em 眉线、0.34em 主标题副标），中文保持系统黑体，元信息 11px、0.1em 字距；卡片小标 `AI MATCH / TRAINING / FRIENDS` 用 0.16em 字距。
- 字号变化通过分档行高补偿（23.8 / 20.4 / 18.7px），三张入口卡和顶栏控件在 1440×900、1280×720、844×390、667×375、568×320、390×844、320×700 七种视口与主线逐像素一致（0 px）。
- 短横屏隐藏英文副标，用“开拍 · 单打”保持单行紧凑；竖屏保留双语副标。

### 竖屏 PWA

- iOS 状态栏样式从 `black-translucent` 改为 `default`，内容不再压到状态栏下面。
- 竖屏时菜单顶栏高度计入 `env(safe-area-inset-top)`，菜单本体同步下移；页面底色和 manifest 的 `theme_color`/`background_color` 统一为纸白，`color-scheme: light`，`min-height: 100vh` 兜底，竖屏菜单隐藏背后的 3D 画布，避免底部出现深色条。
- manifest 移除 `orientation: landscape`，已安装应用跟随手机方向；描述改为“羽毛球单打：人机对战、好友对战与三步训练，支持离线人机。”；构建脚本里 peer/demo 的 manifest 描述同步更新。
