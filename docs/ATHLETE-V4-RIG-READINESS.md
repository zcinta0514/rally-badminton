> 更新：本文件保留原阶段记录。2026-09-19 后续近景贴合、独立绑定与基础动作状态以 [V4 Detail / Rig 检查点](ATHLETE-V4-DETAIL-RIG-CHECKPOINT.md) 为准；用户已授权推进绑定，但未授权替换正式比赛人物。

当前交付是 `appearance-1.0.0` 静态审核候选，**没有骨架、蒙皮或动作**。主体人体顶点与 Hair ref39 相同；精修版改了眼球位置、材质与头发，服装有独立拓扑。静态 QA 通过不证明抬臂、跨步或握拍后的表现。

## 坐标与工程合同

- Blender 源：米制，Z 向上、+Y 朝前、角色左侧为 -X。导出 GLB：Y 向上、-Z 朝前。
- 完整人物根节点沿 Blender Z 抬高 0.024 m，让新鞋底落到地面附近。绑定时以实际鞋底校准接地，不能把这个偏移再次叠加。
- 衣领、袖口、下摆、裤腿口、袜子和护具有独立对象；球衣主体 4 个开口环，短裤主体 3 个开口环。源网格保留连续面带；导出时由 GLB 三角化。
- 球衣使用单层双面表面，独立领口/袖口/下摆提供折边厚度。不要重新给主体加一套重复内翻边；本轮已经实测该做法会产生袖口自交。
- 服装碰撞只对完整 Anatomy 人体计算，没有删除被衣服遮住的身体。未来制作游戏 LOD 时，隐藏身体的优化必须作用于派生资产。

## 参考锚点

GLB 内含 7 个无渲染 Empty：右手握拍点、拍柄轴线导向点、拍面中心导向点、左右脚跟和前掌点。导出名字中的空格会变成下划线。

这些点是静止空间标注，**不是已经校准的握拍姿态或触球解算器**。现阶段手指张开，拍柄方向仅用于定义下一阶段的局部坐标。

| 参考点 | Blender 局部位置（m，根偏移前） |
|---|---|
| grip R | (0.400, 0.087, 0.919) |
| racket handle axis guide | (0.400, 0.087, 0.999) |
| racket face guide | (0.400, 0.087, 1.379) |
| heel L / R | (∓0.193, -0.110, -0.022) |
| forefoot L / R | (∓0.248, 0.092, -0.022) |

先完成右手虎口、拇指与食指的握拍姿态，再把导向点转成手骨局部 socket。接触中心需要结合最终球拍长度、拍面方向重新标定。鞋跟与前掌分别保留锚点，为支撑脚锁定和蹬地滚动准备条件。

## 运行时适配不能照搬旧加载器

核对实际 `src/athlete-import.js` 和现役 GLB，运行时是 **18 个语义骨 + 外部角色根变换**，不是旧计划中的 19 个骨。

| 比赛语义输入 | 新骨架适配方向 |
|---|---|
| pelvis、spineLow、spine、chest | 骨盆到胸椎的层级旋转；spineLow 可以是脊柱链上的插值目标 |
| neck、head | 局部颈部及头部朝向 |
| left/right Shoulder、Elbow、Wrist | 锁骨、上臂、前臂、手；前臂扭转与手指保留独立控制 |
| left/right Hip、Knee、Ankle | 髋、大腿、小腿、足部；鞋底约束另行标定 |

旧 `installAthleteModel` 会把骨骼重建成扁平结构，不能用于新的分层 V4 绑定。后续应建立独立适配器，保留骨长、父子层级和 inverse bind matrices；不要为了套旧接口压平手指或前臂扭转骨。

根位置、比赛朝向、移动速度、`contactAt`、`contact` 和胜负判定继续由比赛状态决定。动画只表现动作，不生成另一套命中或得分规则。

## 下一阶段验证顺序

1. 放置骨架与关节轴，先校验 A 姿、双臂上举、屈肘、屈膝、髋外展及躯干扭转。权重传递只作为初值，肩腋、裆部和护具要逐区修正。
2. 校准握拍手、拍面方向和脚底锚点。抬臂与深弓步时复查衣裤穿插；不直接开启旧 V3 布料模拟。
3. 按准备 → 分腿垫步 → 移动 → 前场弓步 → 头顶击球（区分高远、吊球、杀球）→ 回位制作。每段有准备、触球、随挥、回位标记。
4. 四视角、慢放与触球帧复核；覆盖场地双方朝向、极限够球、快速连续动作切换。记录拍面误差、骨长漂移、支撑脚滑移和衣物穿插。
5. 静态精修版当前 102946 三角形、44 个材质 primitive，不等于比赛场景 draw call 数。正式接入前制作派生 LOD、合并可合并的材质，实测双人、阴影、手机帧耗时和内存后再确定运行时预算。

本轮不修改正式 `athlete.glb`，不发布线上人物替换。人物定稿与真实动作验收仍需分别记录。
