我们在准备高质量实时羽毛球人物动作库，优先级是专业动作、身体骨骼、握拍、真实接触、支撑与完整回位。请贵方确认是否承接包括球员、场地、全链采集、原始数据及动作交付的服务，或仅提供设备／软件；请区分自有、合作与需另行落实的能力。

3. 请提供现有真实羽毛球小样：正反手短发球、被动防守、后场击球各至少一条完整动作，以及一段真实双方连续回合。若只能提供部分，请列明缺项。这是前置预审，不替代 42 个正式试采槽位。需未剪辑正常速度参考、多机原件、拍框／弦面与球头局部高速、手指和足地覆盖、相机标定与时间映射；请勿仅交骨架录屏。
