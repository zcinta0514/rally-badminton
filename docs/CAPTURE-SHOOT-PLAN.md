# 专项动作试采与扩采清单

2026-10-03，规格 rally-capture/2.0；对应 P0-4、P1-3，扩采属于 P1-4。本文是现场执行清单，实际交付与验收状态只更新 [PROJECT-STATUS.md](PROJECT-STATUS.md)。适用 [主规格](MOTION-CAPTURE-SPEC.md) 和 [质量门槛](CAPTURE-QUALITY-GATES.md)。所有数量都是覆盖下限，不是已经取得的数据，也不足以证明总体尾部性能。

## 1. 先完成的观测与标定

| 编号 | 操作及必须保存的材料 | 进入技术动作前的判断 |
| --- | --- | --- |
| C00 | 场地实测、净空与制动区、相机／力台／高速 ROI 布局、自然照明与气流记录 | 双方完整动作可在有效体积内自然完成 |
| C01 | 所有设备的原始模式、时钟链和贯穿 take 的脉冲／曝光记录 | 能量测真实偏移、漂移和丢帧；关键链满足时间预算 |
| C02 | 静态尺度与留出动态参考；中心、两端、边角、足地、头顶；真实速度与遮挡 | 拟合残差和独立误差分别报告；不以静态精度代替动态能力 |
| C03 | 两名球员人体比例、重复静态中立姿势、解剖标记与功能性标定 | 肩带、关节中心及轴的估计方法与不确定度明确 |
| C04 | 肩抬举／绕环／肩带升降，肘屈伸，屈肘与伸肘时前臂旋前旋后，腕屈伸与偏移 | 可区分前臂轴转、腕运动及肩代偿，至少三次可复核重复；不强迫关节极限 |
| C05 | 单脚承重、提踵、前掌滚动、踝屈伸与足趾活动、轻跳落地 | 足部几何和支撑测量一致；真实滚动不被当作整脚滑移 |
| C06 | 球拍尺寸、柄／框／局部弦面关系；安装前后质量、重心、可测挥重；球头几何 | 柄与拍面非刚性关系有观测；附加设备未明显改变动作 |
| C07 | 无设备与带设备的自然握拍、短发、平抽、后场击球对照 | 球员、教练复核握感、挥拍与落地；改变技术则调整安装 |
| C08 | 双机／多机高速局部试击与独立参考、曝光和 SNR 核验 | 实际球头与弦面可辨，关键误差预算成立；不能靠插帧／锐化通过 |
| C09 | 力台零点、六分量标定、量程／带宽／饱和、鞋内压力与光学时间映射 | 记录有效承重范围；未覆盖部位不能报真实反力 |
| C10 | 每次设备／模式变化后的复标与当天收工验证 | 校准有效区间与每条 take 关联；失效区间隔离复查 |

这些记录不计入下面的 42 条。每条技术动作预留至少 1 秒起始与结束余量；完整准备和下一拍启动若更长则延长。局部高速可以只录关键窗口，但全身及全场参考必须不断档并与该窗口建立可验证时间映射。

## 2. 首轮技术小样：36 条

主球员首轮使用右手；陪练真实来球并同步记录。A 端为主球员位于世界 +Z，B 端为世界 −Z，换端实拍，坐标系不镜像。下表六个条件 × 两端 × 每端三条有效完整 take = 36 条；机器计划为每条分配固定 planned slot ID。

| 条件 ID | 主球员技术与连续过程 | 必须看见的重点 |
| --- | --- | --- |
| S-FH-SHORT | 正手短发 → 接对方回球的启动 | 持球／放球、握拍、低位实际接触、发球后准备；不是只拍摆臂 |
| S-BH-SHORT | 反手短发 → 接对方回球的启动 | 拇指与握柄关系、拍面正反、发球恢复；与正手分开处理 |
| R-FH-BLOCK | 受压正手防守挡球 → 制动／恢复 → 下一来球启动 | 被动触点、肘腕轴向、收拍避身及能否重新启动 |
| R-BH-BLOCK | 受压反手防守挡球 → 制动／恢复 → 下一来球启动 | 正反手握拍差异、深屈肘、前臂旋转和躯干距离 |
| O-FH-CLEAR | 后退到位、剪刀步正手高远 → 落地 → 回位 → 下一拍启动 | 肩髋次序、拍杆／拍面、支撑交换和恢复平衡 |
| O-JUMP-SMASH | 后场起跳杀球 → 落地制动 → 回位 → 下一拍启动 | 腾空、局部接触、躯干与手臂协同、落地承重与连贯恢复 |

每条以上主技术触球都是预先指定的严格触球事件，须满足 L0／L1 关键观测与完整动作要求；辅助来回球也保留并逐事件标质量。教练确认技术成立，原始观测完整，才计入有效条数。失败、失误及重拍仍有独立 attempt ID、原件、拒收原因，不删除或改号覆盖。

三条不是三种速度的假设标签：先在自然比赛速度复现技术，实际速度来自测量；主动／被动、来球深浅与节奏的系统覆盖在扩采矩阵另做。每次高强度动作之间由球员／教练决定恢复，疲劳变化记录到 session，不以连续重复换取数量。

## 3. 连续回合：6 段

每类两端各一段，最少 8 次双方合计的真实触球，主球员至少 4 次，不能用慢放、重复帧、拼接或一方单独挥拍凑数。

| 条件 ID | 自然连续关系 | 必要观测 |
| --- | --- | --- |
| Q-DRIVE | 正手／反手平抽交换与换握 | 前臂轴向、紧凑收拍、连续步法、握柄切换 |
| Q-DEFENCE-CLEAR | 受压防守 → 恢复 → 后场高远，陪练按实际出球衔接 | 防守后重新启动、肩髋姿态改变、恢复后的下一触球 |
| Q-SMASH-NET | 后场杀球 → 对方挡网 → 前场弓步处理，再自然续球 | 落地制动、向前启动、弓步承重／推地、再次恢复 |

每段事先指定**至少两个主球员技术转换两侧的触球事件**作为严格局部采样目标，例如杀球与随后网前处理；两事件不能只挑较慢、易拍的连续同类球。可部署多个 ROI 同步覆盖；需换机位时另录新 take，不能把两段拼成一次完整回合。

所有其他触球也记录来源、覆盖与不确定度。局部高速未覆盖的事件标 needs_evidence／reference，不因为同一段另有合格事件而升级为严格真值。每份报告同时列整段身体验收与逐事件严格准入；“6 段连续回合合格”不意味着其中每一次触球都具备局部真值。

至此最低为 **36 条技术 take + 6 段连续回合 = 42 条完整记录**，不含标定、仪器对照、失败尝试及增加统计把握所需的追加试采。

## 4. 留出、选择与当场检查

- 每个六技术×两端条件的 r01／r02 用于开发，r03 预定为留出：24 条开发、12 条技术留出。六段连续回合全部留作连续性验证，合计 18 条留出。留出按整条 take 冻结，不能把相邻帧分进开发与验证。
- slot 分配在清理、重定向与修形调参前确定；按原始质量准入填槽，不按最终动画好坏挑选。拒收日志包含全部尝试、原因与替换对应关系。留出集也必须清理，但使用已锁定的处理配置；发现问题修订配置后，应新增未用于调参的留出批次，旧集只作回归。
- 两端都有开发与技术留出；连续回合为独立验证任务。后续增加不同 session、不同身高比例及真实左手球员留出，以检查跨球员泛化；单一球员 42 条不能支持这些结论。
- 每条拍完即查曝光、覆盖、同步和原始文件完整性；触球／着地附近检查最长缺失段、拍面可辨性、标记身份、手指证据与力台覆盖。现场发现关键不可观测直接记录并安排补采。
- 当天两份分离存储的原始副本，逐文件 SHA256 回读；原件只读，处理版另存。每批导出先核时间轴／坐标／原件关联，再交离线制作，不能拍完大量数据才发现时钟或单位错误。
- p95、max、U95 与置信区间按质量文档执行。需要多少新增 take 由试采误差分布和分块统计确定，不能把 42 条当统计精度保证。

## 5. 小样通过后的五组扩采矩阵

| 组 | 必覆盖的技术／关系 | 条件与数量下限 |
| --- | --- | --- |
| S 发球 | 正手短／长发、反手短发；反手偷后场按教练技术确认单列 | 每技术×两端×至少三条；包含自然准备、放球与接发后的启动 |
| L 前场弓步 | 正／反手网前控制与挑球；搓网、推球有实际技术依据再加 | 四基础技术×主动／被动×两端×至少三条；另覆盖合理触点高度和斜向来球 |
| O 后场 | 正手高远、杀球、吊球、反手高远；剪刀步、跳杀落地有独立样本 | 适用技术×主动／被动×两端×至少三条；按教练确认可行组合，不强制不自然反手跳杀 |
| D 平抽连续交换 | 正手主导、反手主导、换握，主动与受压 | 三类×两种情境×两端×至少三段；每段≥8次双方真实触球、主球员≥4次 |
| R 制动与回位 | 八方向启动、急停、转向；防守挡／抽／挑后恢复与下一拍 | 八方向×两端×至少三条自然串联；三防守技术×两端×至少三段，并含有意不过中心的战术回位 |

扩采追踪技术、来球速度／方向、触点高度、主动／被动、握拍、移动朝向、疲劳与支撑变化；由教练选实际可行组合，不盲目做所有维度笛卡尔积。真实漏接、失衡与不可达另存为失败／边界库，不标为成功动作。主观难度不能替代实测速度。

每阶段先验再扩：L0 原件和观测链 → L1 解算与事件 → L2 Blender 持拍／支撑／避身 → L3 五组实际运行与用户正常速度视觉验收。未通过时指出哪层、哪个事件／部位和原因。专业采集原件尚未到位时可继续旧数据的隔离技术实验，但不能宣布这些门槛已通过。
