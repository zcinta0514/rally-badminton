### 新管线结构

- `scripts/build-athlete-v3.py`（改造）：服装构建段调用新模块；其余（人体、骨架 52 骨、面特征、头发、球鞋）保持原逻辑。
- `scripts/v3_garment_loft.py`（新文件，全自研）：截面环带网格化。核心机制：
  - 每个环向顶点源自对人体相关面集 region 的**射线外包络采样**（`EnvelopeSections`：取射线离开人体前最后一个命中，否则布料会缝进三角肌；z<1.30 用躯干树，z≥1.30 才包手臂）；
  - 前/后深度平面 = 人体自身截面外包络 + 设计松量（`band_profile`/`series_at`），压平胸腹起伏且保证不进入皮肤；
  - 下摆、V 领、肩带线、腿口全部是**逐方位角显式平滑曲线**；z>1.435 截面竖直冻结（消除掠射噪声导致的顶环锯齿），领口向颈环收拢（`pull=smooth(1.45,1.505,z)`），肩谷由布料桥接；
  - 短裤 = 一个 yoke 环带 + 两条腿筒（`merge_objects` 合并），裆部桥面下探到 0.68 封住裤裆缝隙；
  - 服装蒙皮改为**人体 KDTree 最近邻权重传递**（k=6，按 region 约束），替代 z 高度解析公式——静态观感不变，为动作阶段扫清腋下/髋部权重硬伤。
- 内置 QA（构建输出以 `V3 QA` 前缀打印）：逐顶点符号距离穿透检查（当前 jersey/shorts 最小间隙 ≥0.002 m、零穿透顶点）、胸前深度带测量（0.1669–0.1754 m，方差 0.0085，测试阈值 0.016）。
- 领口/袖口/下摆/腰封四条绑带由**沉降后边界环**或**网格化顶环**生长（`strip_from_loop`）；注意条带顶点数是环点数两倍，权重必须每点双份，否则导出器补 `neutral_bone` 导致 three.js skinIndex 越界（已修复并写进测试防线）。
- 球衣花纹仍为本体顶点色；袖子用独立材质 `v3-match-shirt-sleeve`（不能共享带顶点色链接的球衣材质，否则渲染全黑）。

## 六、布料模拟：现状与调参入口

- 管线完整实现（自研 bpy）：代理碰撞体（人体抽稀 0.28）、逐件钉住+短程沉降+当前帧 apply。**默认关闭**（`RALLY_V3_CLOTH=0` 缺省），实验结论：
  - 球衣模拟本身成功，但自由沉降把前片拉出平整度阈值、肩部褶皱破坏 yoke；
  - 短裤裆部桥面自相交会让解算**炸裂**（`RALLY_V3_CLOTH_SHORTS=1` 复现）；
  - Blender 5.x 坑位已修：`collision_settings` 在 modifier 上不在 settings 上；`vertex_group_mass` **权重 0 才是钉住**（写 1.0 等于完全没钉）。
- 当前发布的褶皱是确定性程序化位移（胸前带幅度 ≤3mm，不破坏平整度测试）。后续要恢复模拟：`RALLY_V3_CLOTH=1` 重跑构建，先解决短裤自相交（重新生成桥面拓扑或提高 bending/步数），再用 `restore_planes` 思路把前/后中央带深度夹回设计面。
- 相关开关：`RALLY_V3_CLOTH`（默认 0）、`RALLY_V3_CLOTH_SHORTS`（默认 0）、`RALLY_V3_CLOTH_SLEEVES`（默认 0）。
