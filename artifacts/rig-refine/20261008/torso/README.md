## 视频依据与修改

使用本地实际比赛 `artifacts/match-reference/20261006/match15/2_18_14.mp4`，25 fps。与上一轮 `integration/review-final/pairs` 的同源帧对照。人工观察表明：480 仍向画面右侧承重；481–485 躯干过中并转入跑动方向；487–490 胸肩侧身与前倾最明显；491–496 逐渐回正。521–535 的主要差别仍是腿部伸屈与骨盆换重，本模块仅提供小幅胸廓跟随，未试图单靠脊柱替代换重。

- 三节脊柱按 45% / 35% / 20% 分配附加前倾、水平转向与朝行进侧的倾斜。487 附加转向峰值约 −30°，492 后消退；具体角度为单镜头下的手工三维推断，不是测量值。
- 右上臂在跑动时部分随胸廓；504–521 保留已修正的持拍臂世界朝向，肩的位置随躯干移动。未修改手腕、手指和球拍挂接。
- 头部只跟随附加胸廓水平转向的 35%，峰值约 10.5°；颈部吸收身体侧倾，不额外施加头部侧倾/俯仰旋转。
- 左上臂保留原自由摆臂曲线，并部分随胸廓转向，避免把手臂钉在世界空间。

本模块实际单帧查看了 480、482、484、486、487、489、490、491、493、495、496、504、514、515、521、523、525、527、530、533、535；独立画面对照代理复核了候选 480、484、487、490、493、496、514、527，确认早段侧身/前倾与随后回正有可见改善。这里不声称本模块独立完成全片逐帧验收。

## 合成下沉后的髋部分区残差

可用于合并的是 **`hips-04/rebuild.blend`** 中 `Oct08HipResidual_` 前缀的360个形键及其动画，基于主线程 `combined-02/rebuild.blend` 的完全相同骨动作。不要复制旧诊断候选的动作，也不要把旧候选整个覆盖到主线程合成文件。

本模块只允许髋关节18 cm邻域、静止 `z >= .85 m` 的顶点移动。下肢代理负责 `z < .85 m`。实际改变150个顶点，区域外残差严格为0；此前肩、膝、踝、脚底和原形键全部保留。两个代理的结果必须合并后再做完整身体/球拍/支撑审计。
